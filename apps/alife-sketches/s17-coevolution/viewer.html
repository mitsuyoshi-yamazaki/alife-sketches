S-17 — 二つの側が互いに合わせ合う。進んでいるのか、回っているだけなのか

片側の形質 a と反対側の形質 b が出会うと、位置ごとに a=b→1 / a=1,b=0→w / a=0,b=1→0 の値が付き、その平均が side 0 の取り分になる。 それだけ。つまみは w ひとつ——0 では「相手と同じ位置を持つ」ことだけが利き、 1 では「1 を持つ」ことが相手によらず損をしない。 右下の CIAO 行列は世代 i の side 0 と世代 j の side 1 を全ペア対戦させた勝ち分で、 下三角が「現在の個体 vs 過去の相手」にあたる。

CIAO 行列（縦 = side 0 の世代 ↓新しい / 横 = side 1 の世代 →新しい）。左下の三角が現在 vs 過去。

side 0 が負ける（<0.5） 五分 side 0 が勝つ（>0.5） 対角＝同時代

遅れ断面 D(k) = W(+k) − W(−k)。灰の帯は時間の順序を壊した帰無の包絡線。

位置ごとの「1 の割合」の推移（上 = side 0 / 下 = side 1。横が世代）。

同時代の相手に対する取り分 W(0) の推移（横線が 0.5）。

読み方

下三角が赤く染まれば、新しい side 0 が古い side 1 に勝ち越している。
対角の周りだけに帯ができて、離れると白に戻れば、 勝っているのは「直前の相手」に対してだけで、遠い過去に対しては五分に戻る。
どちらの場合も対角（同時代）の色は同じになりうる——それがこのスケッチの要点。
