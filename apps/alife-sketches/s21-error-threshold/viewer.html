S-21 — エラー閾値。主配列は、複写の誤りの中でどこまで保てるか

長さ L の 0/1 の語が N 個。原点（全て 0）だけ重み σ、他は 1。親を重みに比例して引き、複写のとき各桁を確率 μ で反転する。 それだけ。μ を上げていくと、原点の語（主配列）はある点で急に保てなくなる—— Eigen の理論は長い鎖の極限でその点を μ_c ≈ ln σ / L と言う。 左は今の集団の姿（類ごとの語の数）と、同じ規則の無限個体群版（決定論の写像）が同じ世代に予測する分布（白い点）。 右の掃引板は μ を振ったときの主配列の頻度で、「μ 掃引」を押すと点が一つずつ置かれて閾値が見えてくる。

類（原点からの Hamming 距離 d）ごとの語の数。白い点 = 無限個体群の写像の予測（同じ世代）。

d=0（主配列） d≥1（雲） 写像の予測

掃引板。横 = μ / μ_c⁰、縦 = 主配列の頻度の時間平均。曲線 = 決定論の固定点、破線 = 閉形式 (σ(1−μ)^L−1)/(σ−1)、点 = 走らせた結果。

読み方

左上の赤い棒（d=0）が残っていれば主配列は保たれている。μ を上げると棒は縮み、青い雲が右へ流れて二項分布の山になる。
白い点が棒の高さと一致していれば、有限の N は無限個体群と同じところにいる。ずれるのは閾値の近くだけのはず——それを掃引板で確かめる。
峰+平原では、μ が小さいうちは原点（高い峰）が勝ち、μ が大きくなると対極の平原（低いが広い）が勝つ——survival of the flattest。
