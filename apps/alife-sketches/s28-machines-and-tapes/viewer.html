S-28 — 機械とテープ。読む側と読まれる側が同じ資源である容器で、読みの網は閉じるか

容器に長さ L の記号列が N 本。衝突のたびに 2 本を引き、片方を折り返して 2 状態の変換器にし、もう片方を読ませて新しい列を作る。 折り返される列と読まれる列は同じ資源で、同じ列がどちらの役もやる。表の 1 項は (書き方, 次状態)——書き方 0 はそのまま写し、1 は反転して写す。 書き方の 4 ビットだけで決まる 4 つの族がある: 写し（積 = 読まれた列）・反転（補列）・ 0 詰めと1 詰め（読まれた列に依らない）。枠をクリックすると、その列が「テープとして」と「機械として」の両方で見える。

容器（枠 = 列 1 本。色はその列を折り返した機械の族、明るさは列の値）。書き換わった枠が一瞬光る。

写し（積 = 読まれた列） 反転（補列） 0 詰め 1 詰め その他（状態で変わる）

組成の推移（横 = 衝突数）。相異なる型の数 / 最頻型の占有率 / 閉じている組の割合。

直近の反応（左が新しい）。機械 ⊗ テープ → 積。変わったビットだけ色が付く。

選んだ列の二重性。左 = テープとしての姿（ビット列）、右 = 機械としての姿（折り返した表と状態遷移）。
