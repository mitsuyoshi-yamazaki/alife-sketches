一行で言うと

観測器のノブには2種類あり、無効化される条件が違う。 「どこで切るか」のノブ（閾値・生存帯・集約規則）はレプリケートの分布に隙間があれば噛まない——S-03 では隙間が値域の 73% を占め、事前登録した9通りのスケールが全部同じ答えを返した。だが「値そのものを作り直す」ノブ（連結半径・記述の層）は隙間では守れない。S-02 の反転は切り方では説明できない——半径を固定すれば閾値を 0.05〜0.95 のどこへ置いても答えは動かない（安定幅 0.40〜0.69）のに、半径を 1.5 から 2.5 へ動かすと答えが変わる。隙間は値と一緒に動いてしまうからである。 そして K-9・K-10・K-14・K-15 は1つの構造の4つの面ではなく、「選択」2つ（K-9 の病名・K-10 の治療）と「検査」2つ（K-14 の偽陽性・K-15 の偽陰性）に分かれる。事前登録は選択を固定できるが、検査の代わりにはならない。 そしてこの問題には既に名前があった——地理学の Modifiable Areal Unit Problem（Openshaw 1983。*scale problem* と *aggregation problem*）、統計学の multiverse analysis、ALife の neutral shadow、心理測定の construct validity が、それぞれ本稿の A2・A の多重性・A4・B に当たる。

結果1: 観測器のノブは2種類ある——「切り方」と「作り直し」

これが本稿でいちばん効いた区別である。

切り方のノブ（cut）作り直しのノブ（recompute）
何をする出た数をどこで切るかを変える数そのものを作り直す
例閾値・生存帯・集約規則（平均/中央値/多数決）連結半径・記述の層（記号/配列）・時間窓・粗視化の粒度

切り方のノブは、隙間があれば噛まない（S-03）

S-03 は K-9 を受けてスケールを9通り事前登録し、全部で掃引した。9通りすべてが同じ境界 μ=0.130〜0.155 を返している。 その理由を、105 レプリケートの質量比から機械的に確かめた（raw/gap-hypothesis.jsonl・元データは S-03 raw/replicates.jsonl）:

値域        0 〜 9.0727
最大の隙間  0.9375 → 7.5673（幅 6.6298 = 値域の 73.1%）
次の隙間    0      → 0.8959（幅 0.8959 = 値域の  9.9%）

事前登録した生存帯の端は 0.2 / 0.5 / 0.8（下端）と 1.25 / 2.0 / 5.0（上端）である。 下端3つは全部2番目の隙間（0〜0.8959）の中に、上端3つは全部最大の隙間（0.9375〜7.5673）の中に落ちる。 だからどの帯も同じ集合を切り出す。これが「9通り同一」の機構にあたる。

理由も同じ機構で説明できる。スープの腕の質量比の最大の隙間は 0.4901 → 1.8692（幅 1.379）で、 下端 0.5 と 0.8、上端 1.25 はこの隙間の中に落ちるが、下端 0.2 は落ちない（下の塊の中に入る）。 raw/s03-band-on-soup.jsonl の bandEndpointsInsideALargeGap がそれを機械判定している:

作り直しのノブは、隙間では守れない（S-02）

ここが S-02 と S-03 を分ける。S-02 の連結半径は切り方のノブではない——同じ粒子配置から別の数を作る。 本稿は S-02 の閾値を半径ごとに 0.05〜0.95 の 91 通り動かして、切り方への頑健性を測った （raw/s02-cut-vs-recompute.jsonl）:

半径を固定すれば、閾値は幅 0.40〜0.84 にわたってどこへ置いても答えが動かない。 S-02 は切り方には頑健だった。 それでも半径を動かすと答えが変わる。

隙間は、作り直しのノブを守らない。隙間は「いまの値の分布」にあるが、作り直しのノブは値そのものを取り替えるからである。 S-02 では、ρ=0.08 の同じ1本の配置が、半径 1.5 で 0.000、半径 4 で 0.9844 を返す （S-02 raw/posthoc-cluster-radius.jsonl:4）。 1本の標本が値域の両端を訪れる。隙間は値と一緒に動く。

(d) なぜそうなるのか——基層が個体化を与えているか

感度比は測れるが、測る前に予測したい。6本を並べると規則が出る（raw/cross-sketch.jsonl）:

スケッチ基層「何が1つか」を決めるのは作り直しのノブ結果
S-02連続空間の粒子誰も決めていない連結半径（連続・[1,4] が全部もっともらしい）反転した
S-01反応網（組合せ論）系（maxRAF は反復除去の不動点で一意）無し切り方だけが効く
S-03格子上の連続場系（核 K がモデルの一部）時間窓のみ（定常状態で噛まない）量の選択が効く
S-04記号列基層（1分子＝1本の文字列。同種＝記号列の厳密一致）記述の層（離散・2択）・時間窓反転しない
S-05共有メモリの仮想機械基層（「自分のブロック」＝確保記録 start..start+len）時間窓のみ帰無値が厳密に 0
S-062D 格子基層（事象＝点の埋め直し／2×2 は格子の最小単位）無し特異性が効く

規則: 基層が同値関係（どれとどれが同じものか）または個体の境界（どこからどこまでが1つか）を自分で持っていれば、 観測器は粒度を発明せずに済む。持っていなければ、観測器が必ず発明することになり、その発明の範囲が連続になる。

なぜ連続空間だけが持たないのか。 連続空間の点集合には正準な連結性が無い。「近い点どうしは同じ塊」と言うには近さの閾値が要り、 その閾値は空間には書かれていない。しかも S-02 の系は長さのスケールを複数持つ——相互作用半径 5、平均粒子間隔（ρ=0.08 で約 3.5）、 塊の内部間隔（約 1）——ので、「もっともらしい連結半径」の範囲 [1,4] がそれらを跨ぐ。跨ぐ範囲に浸透（パーコレーション）の転移が入っており、 そこで秩序変数が 0 から 1 まで走る。これが R_knob = 0.98 の正体である。

記号列にはこれが無い。AAABBBCCC… と AAABBBCCD… が同じ種かどうかは、基層が「記号列の同一性」という同値関係を持っているので、 観測器が半径を選ばずに答えられる。残る自由度は層の選択（記号 / 配列）という離散の2択で、外れのほうは R_control で見分けられる。

(e) 事前に危ないと言うための手続き

criteria.json を書く時点で、本番を走らせる前に全部できる:

0. 秩序変数の候補それぞれについて R_control を測る（試走2回）
   → 制御変数に反応しない量は、その場で落とす。どんなノブにも負ける
     （S-04 の記号の層: R_control=0.28 で 12 点のどこでも閾値を跨がない。配列の層は 0.96）

1. ノブを「切り方」と「作り直し」に仕分ける
   切り方 = 出た数の切り位置（閾値・生存帯・集約規則）
   作り直し = 数そのものを作り直すもの（粒度・記述の層・時間窓・粗視化）

2. 作り直しのノブには感度比を測る（試走あと2回）
   感度比 = R_knob / R_control >= 1 なら、掃引の結論を書かず、
   **ノブの掃引そのものを主の結果として報告する**

3. 切り方のノブには、パイロットのレプリケート分布で
   「答えが変わらない切り位置の区間」を測り、もっともらしい切り位置が
