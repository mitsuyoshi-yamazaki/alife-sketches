読み方の要点:

  • ε_S=2 の液滴は反応があると形が崩れる。 同じ ε_S=2 で反応を止めた NC-static（平衡の滴）は瞬間の値で f_nc 0.17〜0.18・パターン 5〜6 個・大きさ 30〜37 だった。反応がある M では Φ=2 で f_nc 0.33〜0.37・8 個・大きさ 13、Φ=4 で 0.49〜0.50・13〜14 個・16〜18 である。供給が増えるほど滴は小さく、多く、いびつになった（Zwicker らの「回転が速いほど滴は小さい」と定性的に同じ向き）。
  • ε_S=3 の塊は材料が入れ替わる形である。 S は位置によらず率 0.01/τ で崩れるので、S 1 個の平均寿命は 100τ である。ε_S=3・Φ=4 のパターンは（瞬間の値で）寿命の中央値 147〜189τ で、半分以上が構成粒子の平均寿命より長く生きた。反応の無い NC-static の滴も長く生きる（中央値 30〜149τ）が、そこでは粒子が入れ替わらない。
  • Φ_pat（パターンに属する S の割合）は、登録と瞬間で ε_S=2 では 10〜20 倍違う（0.02〜0.05 → 0.33〜0.60）。ε_S=3 では 2 倍（0.46〜0.51 → 0.89〜0.93）。この差は観測器の定義から来ていて、系からは来ていない。

時間——すぐ収束しないか

  • 系全体の量は数百τで落ち着いた。 S の数 N_S は、25τ の平均が W の平均の ±10% に入るまで 26〜442τ だった（Φ=2 は初期の S 205 個がほぼ定常の 200 に等しいので 26τ）。以後 2000τ まで漂いは無い（W の傾きの t 値は、相関を考えれば有意といえる大きさではない。食い違いの節）。

選択は働いたか

何をやったか

題材

2 次元の周期箱（L=64）に円板 1024 個（数密度 0.25）。各粒子は型 F（餌）/ S（構造材）/ W（廃物）を持ち、反応で型が変わる:

  • 光 W→F: 太陽の蓄えから率 Φ の Poisson で光子が出て、無作為な W 1 個が吸う（e_ph=50 kT）
  • 崩壊 S→W: 率 k_d=0.01/τ
  • 触媒 F→S: 中心間 1.5σ 以内に S が 2 個以上ある F が率 1/τ で S になる。新しい S の θ は触媒の θ の平均＋N(0, 0.03²)

力は全対に共通の WCA の芯と、型ペアで係数が違う滑らかな井戸（S-S は −ε_S の引力、W-S は +1 の斥力、他は 0）の厳密な勾配である。慣性と熱浴（kT=1・γ=1）を持つ BAOAB の Langevin で動く。割る規則は無い。 型が変わる瞬間のポテンシャルの跳び ΔU_jump は、その反応の化学エネルギー（u_F=50・u_S=40・u_W=0）が払う（払えなければ拒否）。

腕は次の 28 走行（2000τ。較正の 3 本は 200τ）:

  • M: ε_S∈{2,3}×Φ∈{1,2,4}×2 seeds の 12 走行（θ は力学に効かない標識＝中立の対照）
  • A-noWS: 廃物の斥力を切った腕（2 走行）
  • SEL: 凝集 ε_i=2+θ_i（2 走行）
  • A-dusk: 太陽が光子 2000 個で尽きる腕（2 走行）
  • A-free: 尽きた後も光子を払わずに届ける腕（2 走行）
  • NC-dark: 太陽なし（2 走行）
  • NC-static: 反応なし（2 走行）
  • PC-S: 崩壊の率を k_d(1.5−θ) にした選択の較正（1 走行）
  • E-jumpleak・E-freephoto: 台帳の較正（2 本）
  • 刻みの検査（1 本）

観測器（登録どおり）

  • 塊: S-S の r<1.5σ の接触が直近 3 スナップショットで続いた結合の連結成分
  • パターン: 塊のうち 6 個以上・年齢 10τ 以上のもの
  • 形: 慣性テンソルから A と q を取り、穴は 0.25σ の格子で数える
  • 型: S（回り込む）＞R（穴 ≥2σ²）＞E（A≥0.5）＞B（q≥1.35）＞K の優先順
  • 事象: 分裂・融合（資格と 20τ の持続）
  • 群: 隙間 ≤3σ の結びが 20τ 続いたパターンの組（Φ_2）
  • 選択: 生まれた S の θ の窓の差 Δθ̄_birth

妥当性検査

node selftest.js は 57 項目すべて通過（2 分 28 秒）した。主なもの:

  • 力と数値微分の一致（継ぎ目を含め相対 1.9×10⁻⁴）
  • ΔU_jump と全対の和の前後差の一致（3.6×10⁻¹⁵）
  • 反応 1 件の台帳の手計算と、u_S−u_W を下げたときの拒否
  • 熱浴の平衡（⟨K⟩=79.85 に対し N kT=80）
  • 崩壊・光子・触媒の率と θ の継承の統計
  • 形の検出器の較正（六方円盤→K、棒→E、環→R、空孔→穴でない）
  • 分裂の筋書き（12+12 を離す→力による分離、首を W に変える→崩壊による切断）
  • 選択の検出器が植えたずれ 0・0.05・0.2 を 0.01 以内で返す
  • PC-E の 2 腕が⑤不合格で、超過が漏れと一致
  • 刻みの検査
  • 決定性（同じ seed でハッシュ同一）
  • 縮退段 0〜4 × 全 28 腕の組み立て

PC-S の較正は符号だけを見ている（N=300・2000τ で +0.016）。閾値 0.1 に届くかは確かめていない（食い違いの節）。

S4 が足したもの——決定論的な再走

本番の生ログには、登録の目録の列のうち次のものが無かった（食い違いの節）:

  • 型の割合の時系列
  • パターンの寿命
  • 分裂の候補とその成り行き
  • 誕生と死
  • knob の振りでの判定

本家サブプロジェクトへの含意（候補。要件化しない）

  • 型が変わる反応で物性を書き換える粒子系は、割る規則なしに分かれるが、分かれたままでは残りにくい。 増える経路は分裂より核形成が主だった。人工生命の「増殖」を狙うなら、断片が離れたまま生き延びる何か（断片ごとの餌の確保・断片を隔てる層）が要る——S-57・S-58 と同じ結論の側にある。
  • 凝集が強いと、材料が入れ替わっても形が残る（散逸構造）。 自己維持の分かれ目を「パターンの寿命 / 構成粒子の寿命」で測れる。
  • 形質を触媒の平均で受け継がせる（混合による遺伝）と、遺伝する分散が潰れて選択が効きにくい。 選択を観測する設計では、粒子的な遺伝（どれか 1 つの触媒から写す）を既定の候補にできる。
  • 「閉じた系の中の開いた系」の台帳は、型が変わる系でも 10⁻¹³ の精度で閉じ、払わない腕を量まで捕まえた。 設計の型として再利用できる。

限界

  • 原典の再現ではない（sourceFidelity）。Zwicker らは連続体で燃料の化学ポテンシャル差を外で固定し、Pearson は力の無い反応拡散、Ono & Ikegami は格子の跳び移りで斥力だけである。本件はそれらを粒子・対ポテンシャル・有限の太陽・台帳で自前に組んだ。「供給が増えると滴は小さく多くなる」「伸びてくびれて割れる」「環が出る」の対応は定性的なものに留まる。Ono & Ikegami 2001 は書誌と要約の水準、WCA は書誌の水準で、原典で確かめていない。
  • 目録の多くは、登録の観測器ではなく登録済みの knob で読んだ値である。 判定は登録の観測器で行い、knob は併記に留めた。ε_S=2 の液滴について言えることの大半は、結合の持続を 0 にした読みに依っている。
  • S4 の値の多くは再走から来ている。 再走が本番と同じ軌道であることは 23 走行 × 2000 時点の一致で確かめた。ただし再走に足した観測器（候補の成り行きの分類・誕生の出自・死の定義）は S4 が書いたもので、selftest の較正を通していない。とくに死は「資格を得たパターンの最初の消滅または縮小（大半が別のパターンへ移ったものは融合として除く）」、誕生の出自は「新しい塊の過半が直前に資格を持つパターンから来たか」と S4 が定めた。
  • パターンの寿命は t=2000 で打ち切っている。 上四分位（ε_S=3・Φ=4 で 472〜770τ）は下限である。
  • 2 seeds しかない。 ①の ε3・Φ4 の seed 依存、SEL の θ の向きが中立を超えたこと、事後解析の餌の分布は、seed を増やせば動きうる。SEL の |Δθ̄| が中立の 12 走行の最大を超えたのは 2/2 だが、中立の 12 走行は条件（ε_S・Φ）が違い、SEL と同じ力学の中立対照ではない。
  • 2000τ より遅い変化は見ていない（SEL の θ は最後まで下がり続け、PC-S は上がり続けた）。
  • 掃引の外（ceilings/untested-ranges.json）: k_d・k_cat・触媒の条件の個数・kT・密度・井戸の幅・F-S の濡れ・反応の熱を局所の運動へ渡す経路・変異の大きさ・θ が効く性質・型の数・初期の組成。とくに「触媒の平均で受け継ぐ」遺伝の形は選択の観測を強く縛っているのに、振っていない。
  • 反応ごとの熱と跳びの分布（登録の目録の列）は、台帳に流れが記録されていないので書けなかった。
  • 図のダッシュボードでの表示は確かめていない（Playwright で SVG を HTML に埋め込み、明暗両方で目視した）。
