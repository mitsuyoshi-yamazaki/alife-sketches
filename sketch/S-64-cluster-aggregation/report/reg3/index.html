2. 何をやったか

2.1 題材

2 次元の周期箱に直径 σ=1 の円板を N 個（本番は縮退段 4 で N=1024。L = √(Nπ/4φ)、φ ∈ {0.05, 0.10, 0.20}）置き、t=0 は全部単粒子。

  • 主（M-rigid）: 過減衰 Langevin（Euler–Maruyama・dt=0.003τ_B・粒子ごとに独立な雑音）。結合していない対に柔らかい芯 U_c = (25/2)(1−r)²（r<1）。各刻みの後、r < 1.0 の対をすべて結合（切れない）。結合した対には芯の代わりにばね（k=25・自然長 = 生成の瞬間の r）。結合の生成の瞬間に、角を固めるばねを 1〜2 本足す（Henneberg の構成で平面の塊を剛くする意図）。塊を動かす規則は無い。
  • 主の変種（M-flex）: 角を固めるばねを持たない。
  • ※参照（R0・R-0.7・R-1・R-1rot）: 塊の所属表を持ち、塊を大きさ n の冪 γ ∈ {0, −0.7, −1} の率で剛体として δ=0.1σ ずつ動かす運動学的モンテカルロ。R-1rot は回転も与える。接触したら結合して併合。
  • 負コントロール: NC-DLA（結合を持つ粒子は止まる）・NC-nobond（結合を作らない）・NC-ghost（結合は帳簿だけで力を持たない）。

停止: 成分数 ≤ 8、または T_max（φ=0.05・0.10 で 1200τ_B、0.20 で 600τ_B）。NC-DLA は動く単粒子が無くなったら止まる。

2.2 観測器

  • G（履歴）: 結合の生成を時刻順に union-find へ流し、Horton–Strahler の次数を付ける。次数 k の「流れ」（同格以上と合体するまでの生涯）が段 U_k。K_G = 終わりの最大の成分の次数。
  • S（位置だけ）: 対の密度 C(r) の ln–ln を区分直線で当て、フラクタルと「密で平ら」の区間の数を K_S とする。
  • 段ごとの性質: 部品の水準（A・z_parts・ℓ_parts・局所 Df・局所 γ）で、隣の次数との差が帯を越えたら「新」。
  • H-strict: 部品（m ≥ 8）が走行の終わりに分離度 c ≤ 0.2 かつ形の保持 s ≥ 0.9 なら「残る」。
  • Df_MR: S_w=50 で n ≥ 16 の成分の ln n を ln R_g に当てた傾き。

2.3 妥当性検査

  • node selftest.js: 48/48 通過（s4-analysis/selftest.out.txt）。力の数値微分との一致（相対 1e-10）・ΣF=0（8e-17）・セル表と全対探索の一致・二量体の分散の厳密値（0.04326 対 0.043243）・Strahler の筋書き・貫通の筋書き・H-strict の筋書き・一様配置で K_S=0・負コントロールの①と③・決定性・腕どうしの初期配置のハッシュの一致・箱の大きさ。
  • selftest が登録より緩めていたもの: 重心の拡散の正コントロールは登録の [0.92, 1.08]・20 本×100τ_B でなく 0.6〜1.4・24 試行（n=1 で 0.745）。帯の較正は登録の 2^11 粒子・90% でなく 256 粒子・資格 N≥2・m≥4・70%。PC-blob は「遷移が 1 つ以上判定される」だけを見ている。剛さの検査（M-rigid の 64 粒子の塊が 100τ_B で剛い）は selftest に無い。潰れを起こす長い時間の多体の検査は無かった——これが §1.1 を S3 まで通した。
  • S4 の独立検査（§4）: 決定論的な再走 14 本が本番と一致（M 腕 2 本は刻み数・結合数・閉路数・最大の伸びまで、R 腕 12 本は snapshots/ の位置と結合の数まで完全一致。M 腕の打ち切り再走 9 本と S_w=20／50 までの再走 4 本も、その時刻の成分数が timeseries.jsonl・snapshots/ と一致）。合体の木を merges.jsonl から数え直すと 39 走行すべてで K_G・K_G,res・成分数・閉路数・次数の割り当てが一致。配置から C(r) を当て直した K_S も、終わりの配置で runs.jsonl と一致した。

4. 独立の再計算と食い違い

4.1 力学と設計の側

  1. 主の腕の潰れ（§1.1 (a)）: 登録の力学そのものの帰結である（結合した対は芯を失い、自然長を接触の瞬間の距離で固める＋柔らかい芯）。登録は「芯は同じ塊の中の結合していない対にも掛かる（自己回避）」と書き、塊が円板として形を保つことを前提にしていた（M-rigid の角を固めるばね・剛さの検査・安定の見積もり「木状の塊は m≈2〜6」）。意図（重ならない剛い円板の塊）と実際（重なって潰れる団子）がずれた（K-17 型）。
  2. 全 M 走行の数値の破綻（§1.1 (b)）: 決定論的な再走で刻みまで特定した。安定の見積もりの前提（1 粒子のばね ≤ 13 本）を系が破った。
  3. 停止条件を破綻が引いた: 「成分数 8 以下」で止まった M 腕 9 走行は、すべて破綻の数刻みで 16〜65 成分から 8 以下に落ちたものである。
  4. R 腕は構造上ゲル化しない: core.js の gatherOutsideCandidates は動かす塊の粒子を候補から外すので、塊は自分の周期像と接触も結合もしない。閉路が作られない（R 腕の閉路は 24 走行すべてで 0）ので、登録の貫通の定義（周期境界を介して自分とつながる）が満たされることは無い。
  5. R-1rot の回転が大きな塊を歪める: kmcRotate は重心からの最小像で局所座標を取るので、重心から L/2 を越える粒子を持つ塊は回転で歪む。終わりの配置で 1.5σ を越える結合が φ=0.10 で 3 本（最大 5.56σ）、φ=0.20 で 2 本（1.83σ）。部品の形の保持 s < 0.9 が 1%。影響は小さいが、剛体の参照が剛体でなくなる例外がある。
  6. R-1rot φ=0.05 の登録外の打ち切り: 事象の数 4000·N で止まった（§3.5）。

6. 本家サブプロジェクトへの含意（候補）

候補として挙げるだけで、要件化しない。

  • 上位の単位の規則を外すと、その規則が暗黙に担っていた性質が消えうる。 剛体 DLCA の「塊を剛体として動かす」は、動き（D ∝ n^γ）だけでなく「形を保つ」「粒子が重ならない」も担っていた。粒子の規則だけで組むと、動き（D_cm = D0/n）は作用反作用から自動で出たが、形は出なかった——結合が芯を置き換え、自然長を接触の瞬間に固める規則は、熱の揺らぎを縮む向きにだけ取り込む歯止めになった。粒子の規則で上位の単位を置き換える題材では、「上位の規則が保存していたもの（形・体積・剛さ）」を列挙し、粒子の規則の側でそれぞれが保たれるかを別に確かめる必要がある。
  • 自己相似な凝集の階層は、段の数で見ると空間を忘れたランダムな合体と区別がつかない。 Strahler の次数ごとの本数（Horton の比 ≈ 3）まで一致した。「何段あるか」を合体の履歴で数える観測器は、粒子数を決めた時点で答えがほぼ決まる。階層の性質は段の数でなく、段どうしの関係（部品が残るか・性質が変わるか・空間の尺度に分かれるか）に出る。
  • 剛体 DLCA は「新しい性質の出ない階層」の基準線として使える実例になった（登録の5項で判定できた遷移は全部相似、空間では 1 つのフラクタルの領域、大きな部品は残る）。ただし基準線としての比較相手（粒子の規則だけの系）は、今回の形では作れていない。

  7. 完全性の「残差」は状態の破れではない（§4.1）。判定を左右していないが、登録の字句（射影の後の破れの最大）とは違う量である
  8. NC-ghost3 の停止は登録の内部の食い違い: 破れの検出器（配位 > 6 で止める）を「M・NC」に一律に掛けた登録と、NC-ghost3 が成分 8 まで進んで帳簿の配位で①を陰性にするという同じ登録の予測が両立しない。実装は登録の字句どおりに止めた
  9. 生ログの欄の欠け: merges.jsonl に生成の瞬間の距離・2つ目の接触の印・同じ刻みの多重の印が無い（rawLogPlan は求めていた）。parts-retention.jsonl に L_P の内訳（2つ目の接触）と1本目の幾何の c_P・s_P が無い。gr.jsonl は走行の終わりの C(r) だけで、対比の状態の C(r) と区分直線の当てはめの候補が無い（③の knob を S4 が計算していないのはこのため）

4.3 selftest

S4 が 2026-09-27 に走らせ直した node selftest.js（約 40 分）は 127 項目すべて OK・終了コード 0（S2 の申し送りと同じ数）。ほかに記録のみの行が 4 つ（2本目の試走が B で不通過だったこと、2本目の近傍表の再利用が事象の列を保たないこと、3本目の剛さの順序の全項目——閉路の順序だけが成立し、対の距離の変化と R_g の縮みは不成立——、短縮規模の走行の実測値）。selftest が通ることは §4.2 の欠陥と矛盾しない: γ_loc の帯・R 腕の入り込み・PC-blob の S・KS の元の分布は、どれも selftest の検査項目に無い（例えば剛さの順序の selftest は閉路の数の順序だけを見て、登録の他の 2 条件を見ない）。

5. 事後解析（事前登録していない）

以下は登録の決定規則の外で行った。主張の判定（§3.1）には一切触れない。

5.1 KS の代替（seed 6401 のスナップショット）

登録の KS（S_w=50 の尺度変換した大きさ分布・seed を束ねる）は計算できないので、seed 6401 の「S_w が初めて 50 を越えた 1τ_B の点」のスナップショットから成分の大きさを作り、s ≥ 3 の s/S_w で KS を取った（compare-arms.json）。M-rigid3 対 R-1rot: φ=0.05 で D = 0.13（棄却の値 0.36）、φ=0.10 で 0.13（0.35）。M-stiff3 対 R-1rot: 0.23（0.33）。いずれも棄却の値の下。ただし M-rigid3 対 R0 も φ=0.10 では 0.19（0.35）で棄却されず、成分 25〜37 個の KS は R0 との区別もできない（φ=0.05 だけ 0.44 > 0.34 で区別した）。KS は本件の規模では C2k の識別に寄与しない。

5.2 C0 を「拘束が守られたか」だけで読んだら

§4.1 の再走は、上限到達の刻みでも拘束の破れが許容の内側だったことを示した。もし C0 の完全性を残差・配位・重心の3条件だけで読めば（登録はそう読まない）、C0（M-rigid3）は成り立ち、C2k は KS を除いて成立、C2s は φ=0.05 の②が判定不能で条件として陽性にならず成り立たない、C3 は Df の差 0.07 < 0.10 で不成立、C4 は成立（後半の差 0.01 は雑音の内側）となる。φ=0.05 の走行（上限到達 4.75%）の再走はしていないので、そこでの状態の破れは確かめていない。

6. 本家サブプロジェクトへの含意（候補）

人工生命そのものへの知見（候補。要件化しない）

  • 粒子ごとの雑音と拘束（重ならない・結合の伸びの窓・角の窓）だけで、塊を剛体として動かす規則（※）と区別できない段ごとの統計——単位の Df・大きさの伸び・次数ごとの形と Horton の比——が出た。 上位の単位を読む規則を書かなくても、「塊の動きやすさ ∝ 1/n」は射影の和 0 から厳密に、「同じ形の繰り返し」は凝集そのものから出る。※を避けた実装でも、従来の DLCA を基準線として使える見込みがある（ただし本件では前提 C0 が登録の上で崩れたので、主張ではなく観察である）
  • 熱の再構成は剛さの順に効き目を変え、効き目の大きい側（角の拘束なし）でだけ段の質を変えた: 低い段が密な片に畳まれ、その上は片どうしの疎な並び——「新しい性質は最初の段で一度だけ出て、その上は相似」という二段の型。中程度の剛さでは閉路はできるが段の差にならず、部品の 7 割前後はそのまま残った
  • G（合体の木の Strahler 次数）の段の数は、3本の登録を通して粒子数だけで決まった（無作為の木と ±1）。空間の構造も剛さも映さず、付着と合体の区別だけを映す。「何段か」を合体の木の深さで数える指標は、この題材では情報を持たない

作り方への知見（候補。method.md へ追記するかは親が判断）

  • 判定の帯に SE を使うとき、SE が計算されなかったことを 0 として扱うと、その項だけが床の帯で判定されて「新」を量産する。 本件では「新」10 件のうち 7 件がこれだった。SE が null なら、その項は判定しない（判定不能）と決め、帯の計算に || 0 を置かない（S-68 の x || 既定値、S-65 の「記録の無い量を陰性」と同じ族）
  • 腕ごとに別の経路（M 腕のループと R 腕のループ）で同じ検出器を呼ぶ実装では、片方の経路にだけ検出器の呼び出しが欠けても、判定不能として静かに数えられて気づかれない。 各腕で「判定できた数 > 0」を selftest の工程の検査に入れる（K-138 の延長）
  • 前の本の壊れ方を構造的に断つ直しは、次の壊れ方を別の場所に作った（歯止め → 配位の暴走 → 射影の収束）。3本目の壊れ方は停止条件の側に出た。反復法の停止条件（上限到達の割合）を完全性の判定に入れるなら、それが状態の破れと同じものを測っているかを登録前に試算で確かめる——本件では上限到達の刻みで状態の破れは許容の内側だった
  • 正コントロールの統計の許容は、その観測器の推定量の SE から決める。 1試行から変位を1つしか取らない推定量では、10 試行の相対 SE は約 0.3 で、±0.08〜0.10 の許容は検出力を持たない
  • 正コントロールの pass が登録の条件の一部しか見ていないことがある（PC-blob の S、重心の拡散の冪）。pass の式を登録の各条件と一対一で突き合わせる
  • 予測を立てるときに借りた値の窓と、判定する量の窓を揃える（⑤の予測は走行全体の Df、判定は S_w ≤ 100 の Df）
  • 同じ登録の中で、破れの検出器の適用範囲と負コントロールの予測が矛盾しうる（NC-ghost3）。負コントロールごとに「どの検出器が先に発火するか」を登録の時点で書く
  • summary.json の completed は分子と分母で数える集合が違った（腕の走行 24 / 走行表 31）。数の分子と分母を同じ集合で数える

7. 限界

  • 原典の再現ではない（登録の sourceFidelity）。主の力学（剛体円板・結合の窓・角の窓・射影つきの Brownian 刻み）は FBA（Jullien–Hasmy 1995）の「剛体の芯と幅つきの結合」の考えだけを採った自前の設計で、原典の格子・価数の上限・三角の禁止・塊の動きの法則はどれも採っていない。始祖の論文（Meakin 1983・Kolb–Botet–Jullien 1983）の本文には到達していない。Df などの文献値は要旨からの借用で、比較は帯としてのみ行った
  • 主の M-rigid3 の C0 は登録の上で不成立で、C2・C3・C4 は判定不能。§1.2・§1.3 の比較の数字は観察であって主張ではない
  • 縮退段 6: M-rigid3 5 走行（φ=0.05 は 1 seed で、しかも壁時計の上限で t=660 に止まった）、M-flex3 2、M-stiff3 1。条件ごとの判定の多くが 1〜2 seed で、C2-stiff・C4 の「全 seed で分離」は M-stiff3 の 1 走行に依る
  • 射影の有限の dt で、窓の中の揺らぎは名目より大きい（二量体の結合の長さの sd が厳密値の 1.53 倍、三量体の角も同程度。dt=0.001 で 1.41 倍）。再構成の速さへの効果は dt を変えて走らせ直していない（登録の untested-ranges）
  • R 腕の接触の距離（1.0σ）と M 腕の接触の殻（< 1.1σ）が違う。M 腕の塊は尺度が約 5% 大きい。Df・z_S は尺度によらない量で比べた
  • ②の Df_loc と γ_loc は N=1024 では帯が広すぎて判定に効かない（§4.2）。段の質の判定は A・ℓ_parts・φ_max の 3 項に頼っている
  • 剛体の参照の④は測られていない（§4.2）。部品が残るかの剛体との比較は無い
  • KS は登録の形で計算できない（大きさ分布が終わりしか無い）。§5.1 の代替は事前登録していない
  • NC-ghost3 は t=1.09 で止まり、⑥の罠のマスと①の 8 本超の検査は試されていない
  • 1MB を超える生ログ 3 本（raw/reg3/merges.jsonl 3.8MB・timeseries.jsonl 2.4MB・units.jsonl 8.0MB）はリポジトリに入っていない（プロジェクトの恒常指示）。§4 の再計算の多くはこの3本をローカルで読んだもので、ローカルの写しが失われると再現できない
  • S4 の再走は 2 走行（φ=0.20 と φ=0.10 の M-rigid3 s6401）だけ。上限到達の最も多い φ=0.05 の走行（38 分）は再走していない
  • 角の窓の θ0 はスナップショットに記録されないので、配置だけからの角の検査はできない（再走でだけ確かめた）
