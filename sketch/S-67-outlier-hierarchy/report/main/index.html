1.1 乱数の初期条件から、塊（U1）→ formation（U2）→ complex（U3）の 3 段が再現したか。どの D0 と L で出たか

登録の判定では再現しなかった。格子の状態を直接見ると、3 段は種からも乱数からも在った。

登録の判定（D-R）: 主の腕 A1（L=1024・D0 ∈ {0.03, 0.05, 0.08, 0.11}・段 10 で 12 本）で ① 10/12・② 1/12・④ 0/12。正コントロールの A7（種 c0・L=1024）でも ① は陽性で P1 = Δ143・rot +1（原典の値）を取ったが、② は陰性、P2 は 1556 ではなく 532（rot 3）、④ は陰性。決定規則 C1 は「A7 も陰性なら、検出器か規則の側の問題として PC の記録で切り分ける」と定めている。切り分けは §2.4 と §4.3 のとおり規則の側は正しい（登録の SHA-256・種の軌跡・S4 が別に書いた CA が本番のスナップショットを 7 時刻ともセルまで再現）ので、C1 は「未再現（検出器の側）」と読む。

1.2 段の数は、検出器（D-R／D-S）と尺度の自由度でどれだけ変わったか

登録の検出器の出す段の数は、系より配線で決まっていた。

  • D-R の K_R は全走行で 0〜2。3 は構成上出ない（④ が既定のつなぎ方で構成上 0。§4.1②）。K_R = 2 の 4 本（A1_0.08_6702・A5_6716・A6_6711・A7L_256）の ② は、系譜の鎖の判定の偶然の一致で立ったもので（t2 = 4589〜6982）、種の走行 A7 は K_R = 1 だった
  • D-R の knob（K1〜K3・K5〜K11 の 28 値。A7・T = 4000）: K_R は全て 1、① は全て陽性、② は全て陰性。K11 を「空間のつなぎ」にした 1 値だけ ④ が陽性になったが、② が陰性なので K_R は 1 のまま。K4（κ_peak の倍率）は掃引に配線されていない
  • D-S の K_S（t ≥ 500 の最大）は 0〜2。K_S = 2 の 3 本（A1_0.03_6703・A1_0.05_6701・A6_6711）は、3 本とも t = 500 の 1 枚だけで 2 になった——乱数のスープの破片が消えていく途中の配置で、formation や complex の尺度の台地ではない（A1_0.03_6703 は t = 1000 以降 A7 と同じ格子で、A7 の K_S は 1）
  • D-S の knob（K12〜K14。登録どおり ds.jsonl の N(r) から S4 が事後に振った。ds-recount.txt）: 走行ごとの K_S の幅は 0〜3（中央値 1）。m_S = 20（生セル 20 以上の成分だけ数える）にすると 30 本中 19 本が K_S ≥ 2 になり、A7 も 2 になる。w_plateau = 1.5 でも 11 本。ライフゲーム（A11_0.05）はどの値でも 1 以下
  • 登録の比較（C3・K-21）: K_R ≥ 2 の 4 本のうち K_R = K_S は 1 本（A6: 2 = 2）で、過半が不一致。D-R の中の幅 0、D-S の中の幅（A7）1、検出器の間の差（A7）0。登録の文言では「段の数は検出器の分け方に依る」が成立し K-21 は再現しないが、どちらの数も上のとおり配線と過渡で決まっており、この比較からは系について何も言えない

1.3 段ごとに新しい性質が出たか。予測「1→2 は相似、2→3 で複製が消え成長と分化が現れる」は当たったか

登録の判定は ⑥a が 4 本とも「相似」、⑥b は判定不能。ただし U2 の旗の計算が登録の定義から外れており、事後の読みでは 1→2 で「回転」が消える。

  • NC-iid（A12）: 行の仕様に D0 が無く、randomInit に undefined が渡って t = 0 の格子が空、その場で empty で止まった（T_end = 0）。K-142 の較正の本体が走っていない
  • NC-life（A11_0.05）: ①〜⑤ 陰性（① は 2/2 陽性の予測）。U2 の像は 245,583 件出ており、記録された 6000 行の 59%（3522 行）が同じ (rot 0, τ = (−108, −5)) の組——離れた 2 か所の同じ灰の配置が、共再帰の群の定義を満たしている。② が陰性なのは系譜の鎖の判定（§4.1①）による。事後の手続きでも Δ = 1556 の群 20 に対し対照の Δ 8 つが全て 20 で、ライフゲームには Δ に依らない一定の群の背景が在る（止まった灰の同じ配置どうし。Outlier の D0 = 0.05 の走行では対照の Δ の群は中央値 0）
  • NB・RS: §1.5

3.4 knob の感度

  • D-R（K1〜K3・K5〜K11、28 値、A7・T = 4000）: K_R は全て 1。「頑健」に見えるが、② が構成上ほぼ立たないので動く余地が無い。K11（空間のつなぎ）だけ ④ が陽性になり、④ が既定の「系譜のつなぎ」で構成上 0 であることの裏付けになった
  • D-S（K12〜K14、事後に ds.jsonl から）: 30 本の幅の中央値 1、最大 3。m_S が最も効く（m_S = 20 で 19/30 が K_S ≥ 2）
  • K4（κ_peak の倍率）は掃引されていない。κ の 3 段の山は peaks.jsonl に記録されている

3.5 上限（K-26・K-63）

  • 上限に張り付いた統計量: replicationEventCount（③ の元）が生き残った Outlier の走行のほぼ全てで 400 = U1 の複製の候補の上限、lineageCount が乱数の初期条件の生き残った走行の全てで 2000 = 追跡の登録簿の上限（種の走行 A7 は 435）。U2 の像は A7 で 265,114 件、D0 ≥ 0.08 の腕で 300 万〜590 万件出て、書かれたのは 1 走行 1000 件

  • 登録簿の総数の上限（1,500,000）には 1 本も当たっていない。同じ型の 64 の上限は 5 本で当たった
  • 上限の記録のうち size-range.json（未実装）・radius-cap.json（個別に集計していない）・finite-grid.json（近似の検査が空になった走行の t = 50 を一周と記録）は中身が読めない

4. 独立の再計算と食い違い

判定を左右する量に絞って、実装を借りずに（規則表の復号・CA・塊・共再帰の群を ind.js に書き直して）計算し直し、生ログと突き合わせた。生ログの値そのものは S4 の再走と全て一致した（§4.3）。食い違いは、値の意味が登録の定義からずれていることにある。

4.1 判定を動かすもの

  1. ② の「同じ Δ で 2 回続く系譜」が、像が密な走行ではほぼ立たない（detectR.js updateLineage）。像は「直前の像の位置から 32 セル以内」の系譜に次々と足され、鎖の判定は「この像の Δ」と「系譜の直前の像からの経過時間」の一致で行われる。像はほぼ毎ステップ出る（A7 で 265,114 件、系譜の最長の鎖 6756）ので経過時間はほぼ 1 で、Δ（数十〜数千）と一致しない。立った 4 本は t2 = 4589〜6982 の偶然の一致で、種の走行 A7 は陰性。PC2 を拾わない②（K-15 型）。合成の D-R の較正（周期 100）が取れなかったのも同じ配線によると見られる（S4 は合成の走行を再現していない）
  2. ④ は既定の「系譜のつなぎ」で構成上 0（computeActiveU2 が系譜 1 本につき最新の像 1 つだけを返し、computeU3 がそれを系譜ごとに束ねるので、束の大きさは常に 1）。さらに ④ の判定は T_end の 1 時刻だけで行われる（登録は「1 時刻でも」）。knob の「空間のつなぎ」では A7 で陽性になった
  3. 登録の山の規則そのものが P2 = 1556 を落とす（登録の定義の側）。A7 の U2 のヒストグラムには Δ = 1556・rot 0 に 6578 件の山があるが、1556 = 4 × 389 で、Δ = 389・rot 2 の山があり 4 × 2 ≡ 0（mod 4）なので、「基本の山」の規則で高調波として除かれる。389 = 2 × 143 + 103 は塊の側の周期の和で、U2 のヒストグラムはこうした塊の側の共再帰（143・532・389・1310 …。A7 の基本の山は 136 個）で埋まっている。1556 が基本の山に残ったとしても「数の最も多い山」（532 の 8781 件）にはならない。formation の周期が塊の周期の整数倍に乗っていることが、「基本の山のうち最多」という P2 の定義と両立しない
  4. ⑦ の HS-12 は構成上 0（自律的な U1 の型の集合が空集合に固定。部品の型も 'agg' 1 種に潰されている）、HS-23 は ④ が立てば 1.0 に固定（runners.js）
  5. ③ は U2 の複製ではなく U1 の複製の候補の数（dr.replicationEvents は trackU1Duplication だけが増やす）で、上限 400 に張り付いている
  6. 乱択の規則の RS-λ が 1 本も走っていない（run.js: buildRsRows(config).slice(0, A10_countCount) は RS-count 12 本・RS-λ 12 本を並べた配列の先頭 6 本を取るので、段 1 の「RS-count 6・RS-λ 6」が RS-count 6 本になる）。参照点 RP7 が欠けた
  7. NC-iid が t = 0 で空の格子（protocol.js の A12 の行に D0 が無く、Core.randomInit(grid, L, undefined, rng) が全セル 0 を返す。毎ステップの密度の系列 iidDensitySeries もどこからも渡されていない）。K-142 の較正の本体が欠け、C8 の「NC-iid で陰性」は記録の無い量を陰性に数えたものになっている

4.2 判定は動かさないが、記録が読めない・誤るもの

  1. ① は新しい行き先の対（H1new）だけで山を探す（登録は全ての対の H1）。NC-frozen の ① は構成上陰性、ライフゲームで塊の山が立たないのも一部はこれによる
  2. K_S_max が t < 500 のスナップショットを含む（登録は t ∈ [500, T_end]）。S4 が登録の窓で数え直すと 48 本中 11 本で K_S が 1 → 0 に下がる（⑤ の判定は 1 本も動かない）。台地の判定そのものは S4 の実装と全スナップショットで一致した
  3. U2 の旗が登録の定義と違う量で計算されている: F-rep（2 回続いた系譜の有無）・F-div（系譜の鎖の長さの種類）・F-rot（塊の側の山で埋まったヒストグラムの最大の山）。U3 の F-rep は常に偽、F-move は標本の有無で決まる定数、U1 の F-grow は標本が 0（常に「系列不足」で偽）
  4. 単離と除去が登録の介入と違う（§1.4）。単離の「② が立った」は像 2 回以上、除去の対照は距離の条件を見ていない
  5. 篩の腕（A8・A10）で篩の止め方が働いていない（worker.js は spec.arm === 'A8' で篩かを判定するが、変異体の行は armTag しか持たず arm が無い。RS の行も同じ）。生の割合 ≥ 0.25 が 200 ステップ続いても止まらず、16 本の密な変異体が timecap として 3600 まで走った（S3 の重さの一因。A8 は 1 本あたり約 13 分かかっていた）。登録上はどちらも ② 陰性に数えるので判定は動かない。書く側と読む側の欄の名前の不一致（S-61 型）
  6. A9 の参照の軌跡の類ごとの訪問数が Int32 で桁あふれ（orbit_A9ref の類 0 が −1,686,563,974。L = 1024 で 2500 ステップだと空の近傍 k = 0 を 26 億回引く）。「踏まれた類」の数が 139 と出る。A9 は段 6 で落ちたので判定に影響しない（範囲の決まった統計量が範囲の外。S-69 型）
  7. 打ち切られた試行の行が流れ書きの生ログに残っている: ds.jsonl の A1_0.05_6701 は 109 行（完走 1 回分は 29 行）、u2-events.jsonl の A11_0.05 は 6000 行。決定論なので同じ時刻の行は同じ値だが、行を数える集計（ceilings/event-row-cap.json の総数など）は水増しされる
  8. timeseries.jsonl・u3-events.jsonl・collisions.jsonl・seed-ladder.jsonl は書き出されていない（相の判定・F-grow の系列・衝突の成り行きが読めない）。census.jsonl の c2 の経由は全て null

5. 事後解析（事前登録していない）

以下は結果を見てから S4 が足した解析で、登録の判定には一切使っていない。手続きは 1 つ: 2 つの時刻 t1 < t2 の格子の塊（8 連結・5〜400 セル）を突き合わせ、t1 の塊の形を r 回反時計回りに回すと t2 の塊の形になる対のうち、t2 の側が新しい場所（t1 に同じ型の塊が 1 セル以内に無い）にあるものを、並進 τ ごとに束ね、元の塊を包む長方形の隙間 16 以下でつないで 3 塊以上・15 セル以上の群を数える（登録の U2 の像の文言をそのまま 2 時刻に当てたもの。ind.js の coRecurrence）。系譜も山も使わない。

  • 種 c0（formation-a7.txt・図1）: §1.1 のとおり。t = 3000 から Δ = 1556 の群は 30（全て rot 0）、対照の Δ 8 つでは全て 0
  • 乱数の初期条件（formation-random.jsonl・formation-controls.jsonl・図2）: 7000 まで残った 21 本（A11 を含む）について t = 3000 → 4556。Outlier の 20 本の Δ = 1556 の群は 17〜348、対照の Δ 8 つ（1407・1449・1456・1519・1526・1582・1589・1631。143・103・40・63 の非負の和 ±2 を避けて 1400 から 7 刻みで選んだ）の群の数は中央値 0〜28・最大 0〜62。1556 の群が対照の最大を下回った走行は無い（最も近いのは A3_0.25_6702 の 116 対 62、A1_0.11_6703 の 165 対 46）。ライフゲーム（A11_0.05）は 1556 も対照も 20 で差が無い
  • A1_0.03_6703 と A7（same-as-seed.txt）: t = 1000・2000・3000・5000・7000 で、A7 の格子を 90° 回して (390, 755) 並進するとセルまで一致（生セル 909・781・1652・2626・9425）。t ≤ 500 は不一致
  • 格子の大きさ（seed-ladder.txt）: §1.1。L = 384・512 でも格子に収まらなくなった後に群は増え続ける（1947→3503 で 34・38、3503→5059 で 45・123）ので、周期格子の上では formation は自分の写しとぶつかりながらも増える。L = 128 は 2520 で空、192 は群が 2 のまま
  • 変異体の生き残り 29 本（mutant-formation.txt）: t = 1200 から Δ = 1〜2400 の全てで群を数えた（登録の篩なら密で止まる時刻で打ち切った）。§1.5 のとおり、1 つの Δ に 2 つ以上の像を持つ群は 29 本とも 0。群が周期的に現れたのは A8_51（157 セル・5 塊の群が 84 の倍数の Δ に 1 つずつ、計 21）と A8_86（43 セル・4 塊の群が 118 の倍数に 1 つずつ、計 15）で、どちらも生セルが増えず、写しが増えない。初めの 10 行は打ち切りを入れる前の版で全 Δ を走査した（結果は全て 0）

事後解析の限界: 群の数は同じ走行の中で独立でない（同じ formation の写しが何度も数えられる）。対照の Δ は 8 つだけで、背景の分布の裾は分からない。「群が在る」は formation の必要条件に近いが十分条件ではない（ライフゲームでも同じ灰の配置が群を作る）——Outlier の走行で対照の Δ の群がほぼ 0 だったことが、この読みの支えである。complex の「縁と内部の分化」は測っていない。

6. 本家サブプロジェクトへの含意（候補）

候補として挙げるだけで、要件化しない。

  • 組み立ての階層は、2 値の局所規則 1 枚から、上位の単位を書かずに出る——塊と formation の写しとその集まりが、乱数の初期条件の 1024² で D0 ≥ 0.05 の 13 本全てに在った（complex は写しの集まりとしての兆しまで）。ただし出る条件は空間の大きさに強く縛られる（種の軌跡が 2 周期目まで乱されずに収まるのは L ≳ 512）。階層の段の数を増やすことは、系の性質である前に空き地の大きさの要求である、という読み
  • 上の段の周期が下の段の周期の整数倍に乗る（1556 = 4 × 389、389 = 2 × 143 + 103）。「下の段の周期と独立な特徴周期」で段を切る観測器は、この系では上の段を高調波として捨てる。段を時間の再帰で切るなら、周期の独立性ではなく写しの空間的な新しさと群の同時性で切る必要がある
  • 1→2 で「回転」が消える（塊は 143 ごとに 90° 回り、formation は回らずに写る）。段ごとの新しい性質の候補として、自己相似な複製の繰り返しの中にも対称の変わり目がある

  • 縮退の段 10: A1 は 12 本（登録 16）、A2・A3 は 4 本ずつ（8）、A4 は 4（8）、A6 は 1（2）、T は 7000（10000）、A9 は落ちた、A8 は T = 3600。A7・A7L の T = 7000 は段 7 の文言（A1〜A6）の外。D0 ごとの率は 2〜3 本でしか動かない
  • 直す前と後の行が混ざっている（§2.3）。heap-guard で止まった行は無く、判定を動かした形跡も無いが、標本の上限が掛かった旗の値そのものは前後で比べられない
