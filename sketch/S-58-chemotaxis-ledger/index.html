2 型の粒子が化学物質を撒き、拡散し減衰する場の勾配へ自分の燃料で推進し（A は B の物質を追い、B は A の物質から逃げる非相反）、燃料は餌から、餌は有限の蓄えを持つ太陽から来る系で、出たパターンは 4 つの型に収まり、どれになるかは非相反の強さ δ よりも日射 I で決まった。I=0.125 では集まりかけの不規則な網目が 75〜150τ で燃料切れのまま凍りつき（以後 t=2000 まで不変。太陽も餌も無い対照とほぼ同じ姿）、I=0.5 では 2〜8 個の丸い塊が飢えて静止し（δ=0 は A だけ・B だけの塊、δ>0 は A と B が芯と殻や二つ割りに混じった塊）、I=2・δ=2 でだけ全 512 粒子が 1 つの二つ割りの塊（A が後ろ、B が前）になって 0.2〜0.4σ/τ で走り続けた（δ=0.5 は W の 30% だけ動く）。円でない形は主に凍った網目に出て（f_nc≥0.3 の主の 9 走行のうち 6）走る塊は丸く、動く塊の分裂は 30〜130τ で融合して戻り（割れたまま残ったのは、互いに引き合わない A の塊と B の塊が δ=0 で離れた場合など少数）、「離れた小さな塊が組になって共に動く」構造は一度も出なかった。エネルギーは閉じた宇宙全体で、払う 25 走行すべてが散逸の累積の 10⁻⁹ 以内で合い、追跡の運動はすべて燃料で払われていた（太陽の光の 85〜90% は食べられずに腐り、I=2 では食べた燃料の 6 割が推進の損失として熱になる）。日没（A-dusk）で追跡は 150〜200τ で止まり（運動エネルギーは昼の 10⁻¹⁴¹〜10⁻¹²⁷ 倍）、燃料の制約を外した腕（A-free＝S-46 型のタダの非相反）は餌も燃料も尽きた後も昼と同じ速さで追い続け、2000τ で宇宙の初期エネルギーの 35〜37% にあたる払われない仕事を生んだ——ユーザの⑤「A が B を追い B が逃げてエネルギーの消費なしに運動が続く」は、この系では A-free にだけ起き、台帳がそれを捕まえた（超過は払われない仕事の影の計数器と 10⁻⁹ 以内で一致）。事前登録の主張は C2（台帳）と C3（日没で止まる）が成り立ち、C1（①〜④が出る）・C4（追跡と組の源は非相反）・C5（日射の軸が燃料の制限をまたぐ）は成り立たなかった——I=2 でも粒子の 46〜70% が飢えており、供給の軸は最後まで燃料に制限されていた。

4 つの型

① 凍った塊（I=0.125 の全 δ と NC-dark は集まりかけの網目、日没後の A-dusk は昼の二つ割りの塊がそのまま） — 燃料 0・速さ 0 の粒子が、集まりかけの途中の形のまま止まっている（図1 上段・図2 の 2〜4 枚目）。I=0.125 では 12〜20 個のパターン（平均 17〜38 粒子）が 75〜150τ で凍り、以後、t=1000 と t=2000 のスナップショットで塊の大きさ・組成・形がほぼ同じ（例: δ=0.5 seed 5801 は 1000 と 2000 で上位 6 塊の大きさ・A の割合・形の値がすべて一致）。δ=0 では A だけ・B だけの塊が 51〜83%、δ>0 では混じった塊が 72〜84%。緩く詰まった網目なので f_nc は 0.37〜0.79 と高い。太陽も餌も無い対照 NC-dark（50τ で凍結、19・18 パターン、Φ_pat 0.69・0.77、f_nc 0.38・0.34）とほぼ見分けがつかない——I=0.125 の日射は、この系では「日射が無い」のとほとんど同じに働いた。 （事後）足元に降る日射 0.12/粒子/τ が基礎代謝 0.2/τ を下回るので、燃料が溜まらず、餌のある所へ動く燃料も作れない。飢えた塊は割れずに凍る——登録が I=0.125 の分裂の経路として予想した「養えない大きさの塊が飢えて割れる」は起きず、M-δ0 の④で予想した「飢えと回復の繰り返しの振動」も起きなかった。

② 飢えて静止した丸い塊（I=0.5 の全 δ、I=2 の δ=0） — 2〜8 個の、密に詰まった丸い塊（f_nc 0.00。図1 中段）。重心はほとんど動かない（パターンの速さの中央値 0.004〜0.034σ/τ）が、粒子は塊の中でゆすられている（⟨|v|⟩ 0.07〜0.09。I=2・δ=0 では 0.44〜0.46）。I=0.5 では粒子の 80〜98%、δ=0・I=2 では 46〜49% が飢えている。組成は δ で変わる: δ=0 では A だけの塊と B だけの塊が別々に並ぶ（単一型が 69〜70%）。δ=0.5 では混じった塊が 59〜79% で、その多くは芯と殻（片方の型がもう片方を包む）。δ=2 では B の多い混合の塊（A の割合 0.21〜0.26、芯と殻）と A だけの塊が並ぶ。I=2・δ=0 は A の塊と B の塊が接しただるま形（f_nc 0.51・0.83）で、Π は −0.16〜+0.10 と符号が揺れる（後述: これは追跡ではない）。W の状態に入るのは 150〜300τ（δ=2・I=0.5 seed 5801 は 675τ）で、以後 2000τ まで 1300〜1850τ 続いた。

③ 動く二つ割りの塊（I=2・δ=2 の 2 走行、A-free の 2 走行） — 系の全 512 粒子（または 491＋21）が 1 つの塊になり、A の半分と B の半分が接して並ぶ二つ割り（A と B の重心の距離が回転半径の 1.09・1.26 倍（δ=2・I=2）、0.89 倍以上（A-free）。一様な円板を半分ずつ塗ると 1.2 倍）。δ=2・I=2 の 2 走行は丸く（f_nc 0.00）、A-free は細長く伸びることがあった（0.21・0.66）。δ=2・I=2 では 0.19 / 0.36σ/τ（パターンの速さの中央値）で走り、P_AB = +0.47 / +0.35（A は最寄りの B へ向かう）、P_BA = −0.25 / −0.12（B は最寄りの A から離れる）なので、A が後ろから押し、B が前で逃げる向きに進む。 小さな彗星が融合を重ねてこの 1 つに育った: seed 5801 は t=30 の 20 個 → t=100 の 6 個 → t=200〜1000 の 3 個 → t=1537 に 512 粒子の 1 個、seed 5802 は 13 → 9 → 5 → 3 → 2 → t=1274 に 1 個。途中で半分に割れても（seed 5801 の t=687 に 512 → 284＋228 など）30〜130τ で融合して戻った（下の「分裂」）。動いていた時間は seed 5801 で t=25〜1150 と 1175〜2000、seed 5802 で t=25〜350・375〜675・700〜2000（短い停止を挟む）。 （事後）追う側が飢える: t=2000 の平均燃料は A が 0.20 / 0.13、B が 0.35 / 0.83。前を行く B が未踏の餌を先に食べ、後ろの A は食べ残しを食べる形である（A-free でも t=1500 で A 0.27〜0.29・B 0.38〜0.40 と同じ向き）。

③′ 間欠的に動く混合の塊（I=2・δ=0.5） — 1〜2 個の大きな混合の塊（256〜360 粒子）が、W の 30% の時間だけ 0.1σ/τ 以上で動き、残りは止まる（seed 5801: t=375〜600 と 1800〜1950 に動き、600〜1800 は止まる）。Π 0.22〜0.30 は P_AB だけが正（0.22〜0.26）で P_BA はほぼ 0（−0.04・0.00）なので、A が B を押しているが B はほぼ逃げていない。

何をやったか

題材

2026-09-25 のユーザ直接指示「S-46 や SwarmChemistry のように、オブジェクトの引力/斥力がテーマのシミュレーションのスケッチを数本つくれ」の C（backlog #64）。ユーザが挙げた 5 項目（①分裂 ②円でない形 ③小→大 ④すぐ収束しない ⑤エネルギーの保存とタダの永久運動の抑制）を観測量へ写し、この本固有の⑥追跡 ⑦日没で止まるか ⑧供給の軸が燃料の制限をまたぐか、を足した。エネルギーの設計はユーザ選択の「閉じた系の中にある開いた系」（太陽光を受ける地球のメタファー）。淘汰圧には繋げない（粒子は増えも死にもしない。登録の _comment に検討の結果）。

  • 系: 周期境界 L=64 の正方の箱に硬い円板 N=512（A 256・B 256）。A は物質 α を、B は β を撒き（1 質量/τ、費用 0.2/質量）、場は格子 64²（h=1）で拡散 D=5・減衰 k=0.2（遮蔽長 5σ）。粒子は応答行列 A:(α:+1, β:+δ)・B:(α:−δ, β:+1) で重みづけた勾配へ tanh で飽和した推進力（最大 1）と探索の力 0.2 を出す。推進の仕事は燃料から ΔK/η_m（η_m=0.25）を引いて払う。燃料 0 の粒子は加速できない（減速はできる）。基礎代謝 0.2/τ。餌は太陽から各節点へ I/τ ずつ注がれ、0.02/τ で腐る。粒子どうしは非弾性の接触だけ（運動量を保ち、運動エネルギーを熱へ落とす）
  • 掃引: δ ∈ {0, 0.5, 2} × I ∈ {0.125, 0.5, 2.0} × seed {5801, 5802} の主の 18 走行（2000τ）、A-dusk（δ=2・I=2・太陽が t=1000 で尽きる）2、A-free（同じ条件で推進と撒く費用を払わない）2、NC-dark（太陽も餌も無い）2、NC-blind（場を読まない、I=0.5）2、台帳の較正 E-eatleak・E-heatloss（200τ）2、格子の検査 h=0.5（200τ）1 の計 29 走行
  • 窓: 過渡 [0,500]、事象の観測期間 O=[500,2000]、状態の判定窓 W=[1500,2000]。A-dusk・A-free は昼の窓 O_day=[500,1000]、判定は日没の 500〜1000τ 後の W

観測器（事前登録した 8 つの量）

①持続的分裂の件数と率 Γ_f（閾値: 3 件以上かつ 0.1 件/パターン/100τ 以上）②円でない形の割合 f_nc（0.3 以上かつ Φ_pat 0.1 以上）③共に動く組の割合 Φ_2（0.2 以上かつ速度を入れ替えた参照からの超過 0.1 以上）④すぐ収束しない（3 系列の τ_relax・W の傾き・自己相関の山・事象の率かパターンの速さ）⑤台帳（閉じの残差と区画ごとの収支が散逸の累積の 10⁻⁹ 以下、払われない仕事 0、日没後の太陽 0）⑥追跡 Π = P_AB − P_BA（0.05 以上、速度を型の中で入れ替えた Π_perm からの超過 0.05 以上、被覆率 0.1 以上、⟨|v|⟩ 0.01 以上）⑦日没で止まるか（K_ratio ≤ 10⁻² で止まった、≥0.5 で止まらない）⑧燃料の制限（飢えた粒子 ≥20% か平均燃料 ≤20% で制限あり、≤2% かつ ≥80% で制限なし）。

1. なぜ I=2 でも飢えるか——足元の日射

粒子が食べられるのは、自分の位置の CIC の 4 節点の餌だけである。塊の中の粒子は、ほぼ自分の足元（六方に詰まって 1 粒子あたり 0.955σ²）に降る日射しか受け取れない。足元の日射 I×0.955 と実測の摂食を比べると:

2. 追う側が飢える

走る二つ割りの塊では、前を行く B が未踏の餌を先に食べ、後ろの A はその食べ残しを食べる。t=2000 の平均燃料（f/f_max）は δ=2・I=2 で A 0.20 / 0.13、B 0.35 / 0.83、δ=0.5・I=2 で A 0.23 / 0.21、B 0.36 / 0.48。非相反な追跡の役割（追う・逃げる）に、燃料の非対称（追う側が貧しい）が付いてくる。δ=0（追跡なし）では A と B の燃料の大小は seed で入れ替わる（A 0.33 / 0.53、B 0.38 / 0.28）。

3. 分裂は融合で戻る——S-57 の問いに対して

S-57 の S4 は「割れたまま残る分裂には、断片を引き離す何か（流れ・燃料・選択）が要るのではないか」と問いを残した。S-58 は燃料で走る粒子の系なので、その「燃料」の枝に一つの実例を与える（事後の読み）:

  • 燃料で動ける世界では、割れた断片は追い合って戻った（上の表: 30〜130τ 後に融合）。払わない A-free（燃料の上限すら無い）でも同じだった。場を介した同型の寄り集まりが 15〜20σ まで届き、箱が 64σ しかないので、断片は互いの引き寄せの届く所から出られない
  • 割れたまま残ったのは、断片どうしを引き戻す力が無い組み合わせだった: δ=0（A と B が互いに引き合わない）で、A と B が接していた塊が型ごとに分かれた 2 件。燃料は断片を動かすが、引き離しはしなかった
  • 燃料の尽きた世界では、割れずに凍った（I=0.125・NC-dark・日没後）。動けなければ離れることもできない
  • よって、少なくともこの系では、燃料（能動的な運動）だけでは「割れたまま残る」に足りない。残るのは断片どうしを引き戻す力が無いときで、それには断片を引き離し続ける別の向きの力か、引き寄せの届かない広さか、断片が違う性質を持つこと（型の違い・選択）が要る——というのが S-58 から言える一言である。箱の大きさと場の到達距離の比は振っていないので、広い箱で残るかは分からない

4. 閉じの残差は丸めの累積で、時間に比例する

払う腕の閉じの残差は、主の腕・A-dusk・NC-blind で t=100 の 1.5〜7×10⁻¹¹ から t=2000 の 2〜9.6×10⁻¹⁰ まで、ほぼ時間に比例して増えた（NC-dark だけは 50τ で止まったあと 1.5×10⁻¹¹ で一定）。区画ごとの収支の最大は 3×10⁻¹¹ 以下で、どれかの流れの記帳漏れを示す区画は無い。H への小さな加算の丸めが H の大きさに比例するという読みと合う。補償和（Kahan 和）で累積すれば数桁下がるはずだが、試していない。

本家サブプロジェクトへの含意（候補）

候補として挙げるだけで、要件化しない（採否はユーザが個別に判断する）。

  • 「閉じた系の中にある開いた系」の台帳は、タダの非相反を桁違いの差で検出できた。払う腕の閉じの残差 ≤9.6×10⁻¹⁰ に対し、払わない腕は 0.26〜0.27（10⁸ 倍以上）で、超過は「払われなかった仕事」の影の計数器と一致した。ユーザの設計の型（台帳 2026-09-25-01）を実装で確かめた例として、人工生命の要件 の REQ-7 の注記の実例になりうる
  • 集まることが飢えを作る（事後）。足元の日射しか食べられない設計では、塊になるほど 1 粒子あたりの供給が減る。これは「有限の資源をめぐる競合」を、規則に書かずに形から作る手段の候補になる。とくに追う側が飢え、逃げる側が先に食べる非対称は、繁殖と変異を足せば（登録の _comment にある分裂と遺伝の案）、追う・逃げるの役割に掛かる選択圧になりうる
  • 凍結は、動く形の化石として残る。燃料が尽きると昼の形のまま 900τ 近く（t=2000 まで）動かない。「死んだ塊」と「生きている塊」を形では見分けられず、燃料と速さで見分ける必要がある（観測器の設計への含意）

限界

  • 原典の再現ではない（sourceFidelity）。原典（Agudo-Canalejo & Golestanian・Saha ら・Soto & Golestanian）は連続体または過減衰の点粒子で、場は拡散のみ（抽出の限り減衰項なし）、運動のエネルギーは勘定されない。本件は物質を型ごとに 2 つにし、減衰・応答の飽和・慣性と摩擦・硬い円板・燃料と太陽の台帳を足した。原典の確認は ar5iv のモデル節を WebFetch（頁を小さなモデルに通して答える）で抽出した水準、Meredith らは抄録、Keller & Segel は書誌のみ。相図の数値は原典と比べられない。定性的には、Agudo-Canalejo & Golestanian の「静止した塊が対称性を破って自己推進する巨大な塊になる」に当たる走る二つ割りの塊が出たが、Saha らの「進行する帯・迷路」は出ていない
  • 型の区分は事後の代用である。登録の第 1 層・第 2 層の型は実装されておらず、パターンごとの速度も残っていないので、目録の「状態」は走行全体の時系列から付けた。パターンの組成（二つ割り・芯と殻）はスナップショット 1 時刻の瞬間の接触で数えた
  • Π_perm と Φ_2,perm が評価できない。⑥の陽性はそれを除いた 3 条件での値で、C3 の判定もそれを前提にする（A-dusk の昼・A-free の W の Π は 0.43〜0.77 で閾値から遠いので、Π_perm の結果で覆る可能性は低いと読むが、確かめていない）
  • パターンの速さは、境界をまたぐ塊で歪む（重心を生の座標の平均で出している）。④の「動き続ける」の枝と、目録の「動く塊」の区分に効く。目録の区分は中央値ではなく 25τ ごとの多数決で付け、1.2σ/τ を超えるサンプルは動く側に数えていない
  • 上限に張り付いた量（K-26）: ①パターンの大きさは系の粒子数 N=512 に張り付いた（δ=2・I=2 と A-free の 1 つの塊）。二つ割りの塊が箱が広ければどこまで大きくなるか、有限の大きさで止まるかは分からない ②閉じの残差が合格線 10⁻⁹ の 0.2〜0.96 倍、A-free の一致が 0.99 倍、E-heatloss の漏れの一致が漏れの量で割れば 1.5 倍。丸めの累積が時間に比例するので、同じ実装で走行を長くすると、物理の漏れが無くても⑤は不合格になる。判定はこの 2000τ に限って成り立つ ③回り込む塊の記録（ceilings/spanning.json）は 1 走行 200 件で打ち切られ、4 走行（A-dusk・A-free・δ=0 と δ=0.5 の I=2 の各 1）がその上限に達した ④I=0.125 では粒子の 11〜33% がパターンの下限 n_min=6 未満の群れにいた（ceilings/below-nmin.json）
  • 格子の刻みに 2〜3 割依存する。h=0.5 の 200τ では、パターン数 +29%・平均大きさ −26%・Π +21%（Φ_pat は −0.7%）。目録の「塊の数と大きさ」は h=1 の値であり、粗くなる速さの数値は格子の刻みを含んだ値である。比較は 200τ・1 条件・1 seed だけ
  • 2000τ でなお漂っていた系列がある。登録の W の傾きの検定（5 つの 100τ の塊の回帰。登録の「15τ の塊 5 個」は解釈が定まらなかったので S4 がこう読んだ）で有意だったのは、δ=0・I=0.125 seed 5801、δ=0・I=0.5 seed 5801、δ=0.5・I=0.125 seed 5802、δ=0・I=2 seed 5802 の E_sub と、A-free seed 5801 のパターン数と平均大きさ。これらの走行の「W の状態」は 2000τ 時点のもので、最終状態とは呼ばない
  • 記録の欠け（notes.md の親からの追記）: S3 は 2 回に分かれた。1 回目に完走した 28 走行の「追跡が曖昧だった事象」（ceilings/tracking-ambiguous.jsonl）は記録されていない——0 件だったのではなく数えていない。記録があるのは 2 回目の格子の検査 1 本（1 件）だけ。1 回目の run.log と壁時計も残っていない。完走済みの 28 走行は再計算していない（S2 が h=1 では手直しの前後でビット同一であることを確かめている）
  • seed は 2 つで、凍結の条件の一致は独立な標本の一致ではない（whatSeedChanges）。主の腕の条件ごとの結論は 2 走行ずつに拠る
  • 掃引の外（ceilings/untested-ranges.json）: 相反な交差結合、同型の寄り集まり s の変化、型の比、場の遅れ（D と k）、η_m・基礎代謝・撒く費用、探索の強さ、N と箱の大きさ、物質を食べる型、型ごとに違う餌は試していない。とくに箱の大きさ（L=64）と場の到達距離（15〜20σ）の比は、「分裂が戻る」「全粒子が 1 つの塊になる」の両方に効いている可能性がある
