1. 問いへの答え

1.1 粒子の反発と触媒反応だけから、一様な初期状態で何段が出たか

!図1

物として出たのは 1 段（膜分子の斑点）だけで、閉じた細胞と細胞の群れは出なかった。登録の段の数 n_T は全走行で 0 だが、これは観測器の年齢の単位の誤りで膜の段が構造上立たないためで（§4.3）、年齢を刻みで数え直すと膜の段は被覆の閾値 0.5 のちょうど上下を行き来する（事後）。

段何が出たか（M-hi・2 seeds。最終状態と W=[30000,40000]）登録の段の条件在否
U1 膜の断片膜のサイト（μ ≥ 0.5）が 503・504（全 4096 の 12%）。6 サイト以上の成分が W の平均で 51.0・55.1 個、大きさは 11〜13 サイト、形は直径 3〜4 サイトの斑点（内部のサイトの割合 ι_int ≈ 0.07〜0.09）。全 M の 50.4%・50.8% が U1 に在る（S4 がスナップショットから数え直して一致）L1: U1 の M の被覆 ≥ 0.5 かつ年齢の中央値 ≥ 500 刻み記録は 0（年齢の単位の誤りで構造上立たない）。刻みで数え直すと際どい: 被覆 0.47〜0.51 が閾値 0.5 を行き来し、2000 刻みのうち資格を満たした観測は 21 中 5（事後）

斑点は t ≈ 1000〜2000 刻みで出揃い、あとは数も大きさも動かない（図2a）。等間隔に近い並び（図1）は、一様な状態が分離に対して不安定で特定の波長が選ばれた、という登録の静的な計算（staticPrecomputation.linearStability）の読みと矛盾しない。ただし登録が見込んだのは「軸の向きに並んだ M の線が交わって区画を閉じる」ことで、実際には線ではなく丸い斑点が出た。

等方の M（I-hi）でも同じものが出た（図1 右）: 膜のサイト 482、U1 は W の平均で 53.7 個、最大 14 サイト、有界な囲いは 1 サイトの 3 個だけ。登録は I-hi を「構造はあるが目当てではない対照」とし、M-hi と違う形（厚い塊・連続相）を見込んでいたが、両者は図でも数でも区別がつかない。理由の 1 つは §4.1 の表の読みで、実装の表では一様な組成での X→M のエネルギーが等方と非等方で同じ（Δφ = +3.261 kT）になり、向きの効果が隣の並び方にしか入らない。

低い供給（M-lo・I-lo）では膜のサイトが 0〜4 で、斑点も出なかった（図2a）。代謝は一様に近い形で生き残った（§3.3 の C4・§4.5）。

1.2 段ごとに新しい性質が出たか

細胞の段と群れの段が無いので、登録の「細胞の段の新しい性質」（④: 区画の個別性・自己維持・分裂による再生産）は問えなかった。膜の段（斑点）には 2 つの性質が見える。どちらも非等方と等方で同じだった。

  • 選択的な障壁（規則由来）: Π = K_A / K_X が M-hi で 0.072・0.071、I-hi で 0.077、R-cell で 0.072（登録の閾値 0.3 より小さい）。膜のサイトと隣の外側の濃度の比が、A では X の約 1/14 で、A を締め出して X は通す——親水の A と M の斥力が強く、中性の X と M の斥力が弱い（実装の表では基底より弱い）ことから直接に従う
  • 素材より長く続く（事後・事前登録していない）: M-hi の最終状態から同じ核で 2000 刻み続けると、51 個の斑点のうち 40 個が同じ個体（相互過半の対応）のまま続いた。I-hi では 54 個中 44 個。M の化学的な滞在時間 τ_M は全腕で 462〜485 刻みなので、斑点の寿命の中央値は τ_M の 4 倍より長い（登録の selfMaint の閾値 3 を越える）。日没の後は 500 刻みで膜のサイトが 494 → 8、1000 刻みで 0 になった（A-dusk・図2a）——太陽が支える散逸構造である
  • 向きのそろい（規則由来）: 無い。記録の S_align は M-hi で −0.27・−0.28 だが、これは接線の代わりに法線を測っていたためで（§4.6）、登録の文言（近傍の差のベクトルの主軸）で取り直すと −0.00〜+0.07。いずれも閾値 0.3 に届かない。等方の I-hi は定義どおり ≈ 0

形の分類（blob / line / ring / net）は実装されていない（u1Topo_W が notImplemented）。図で見る限り斑点は丸いが、ι_int が 0.07〜0.09 と小さいので、登録の閾値（blob は ι_int > 0.2）では「line」に分類される側にいる。

1.3 下の段は上の段の部品として残ったか（h12・h23）

問えなかった。 h12（膜が細胞の部品として残るか）と h23（細胞が群れの部品として残るか）は、細胞の段ができた窓 W2・W3 で測る量で、細胞が 1 つもできなかったので全走行で「L2 未形成」（runs.jsonl の h12・h23_lineage・h23_ident がすべて notApplicable）。S2 が本番の経路へ配線した厳密版（壁のサイトの集合の重なり）は、生ログの上では一度も値を持たなかった。

1.4 置いた細胞（R-cell）は維持されたか

維持されなかった。 壁（六角距離 6 の輪の 36 サイト、μ = 0.8）は t = 100 の観測で膜のサイト 0 になり、細胞は t = 100 で「死」と記録された（events.jsonl・cells.jsonl: 誕生 0・面積 91・内腔の a の平均 10・最長の年齢 0）。その後の成り行きは原典（O0）の筋書きと違う:

  • 中身の代謝が死んだ背景へ広がった。背景は供給 S_hi の「死んだ状態」（A = 0）で置いたが、全 A は t = 0 の 910 から 500 刻みで 2620、2000 刻みで 20125、3000 刻みで 27009 に増え、活性サイトは 91 → 3182 になった。双安定の系で、生きた状態が死んだ状態へ前線として攻め込んだ形である
  • その後は M-hi と同じ斑点の状態になった（W の全 A 26900・膜のサイト 495・U1 55.6 個。M-hi は 26410〜26868・503〜504・51〜55）。図2a の緑の線

壁が数十刻みで崩れたのは、物理よりも実装の寄与が大きい（事後・事前登録していない。§5.1・図3a）: 同じ seed で 200 刻みだけ、対のエネルギーの表（実装の読み／登録の加算の読み）と壁の M の向き（S2 の割り当て／登録の文言「辺に平行」）を入れ替えると、本番と同じ組み合わせでは壁の膜のサイトが 20 刻みで 8、100 刻みで 0 になり、登録の表と辺に平行な向きでは 200 刻みで 31/36 が残った。ただし後者でも 100 刻みまでに輪のどこかが切れて内腔が外とつながったので、登録どおりの系でも閉じたまま保つことは保証されない。

欠けた細胞の参照 R-gap は、欠けが作られておらず R-cell と同一だった（§4.4）。O0 の「欠けから A が漏れて崩れる」型の確認は読めない。

1.5 寄生 P を足した選択の腕で、区画は寄生を抑えたか（淘汰圧へ繋げた腕）

!図2

区画（細胞）が 1 つもできなかったので、「区画が寄生を抑えるか」という問いは立たなかった。起きたのは、区画の無い系で寄生が全体の代謝を崩すことで、非等方（SEL-M）と等方（SEL-I）の軌跡は重なった。

  • SEL-M（非等方・s = 0.2）: P の割合 f_P = P/(A+P) が 0.222（t = 0）→ 0.415（2000）→ 0.719（5000）→ 0.872（10000） と上がり、その間に全 A が 28672 → 3100、活性サイトが 4096 → 214 に落ちた。膜のサイトは t ≈ 1000 に 353 あったが、M の生産が落ちて t = 8000 で 0。t = 15000 以降は活性サイト 10 前後の「死んだ状態」で、f_P は 0.5 付近へ戻った（W の平均 0.519）
  • SEL-I（等方）: 同じ形で、f_P の最高 0.879（10000）、W の平均 0.517
  • SEL-0（中立・20000 刻みに短縮）: 代謝は生き残り（活性サイト 2837）、斑点も M-hi と同じく出た（U1 57 個）。それでも f_P は 0.222 → 0.349 へ単調に上がった（Δf_P = +0.113）
  • 登録の判定 ⑨（Δf_P ≤ −0.05 かつ ⑥ 陽性）は 3 腕とも陰性。Δf_P は SEL-M +0.297・SEL-I +0.295・SEL-0 +0.113

W の f_P（約 0.52）は「寄生がどれだけ勝ったか」ではなく、死んだ後の状態で A と P を同じ速さで作る経路——未触媒の k0（X→A と X→P が同じ k0）と崩壊の逆（Y→A と Y→P が同じ k3）——の比 1 : 1 を映している。SEL-0 の単調な上昇も同じ源から来ると見られる（事後の概算: この対称な源は 1 種あたり 1 刻み 約 0.3 個で、A+P 約 27000 に対し f_P を 0.5 へ引く速さは 1 刻みあたり約 5×10⁻⁶、20000 刻みで約 0.1。観測 +0.113 と同じ桁）。登録の「中立の対照」は f_P(0) = 0.222 に対して中立ではなかった——閾値 −0.05 は、この上向きの流れに逆らって判定することになっていた。

2. 何をやったか

系（criteria.json の system）: 2 次元の三角格子 64×64・周期境界。サイトごとに種の数だけを持つ（W 水・A 自己触媒・X 資源・Y 廃物・M_0/M_1/M_2 向きを持つ膜分子。選択の腕だけ寄生 P）。1 刻み = 全サイトを無作為な順に 1 回ずつ訪れ、種ごとに粒子の数だけ試行を引き、隣への移動・M の回転・同じサイトの中の反応（A が X から A と M を作る触媒、全種の Y への崩壊とその逆）を、1 粒子のエネルギーの変化（隣までの対の斥力と化学ポテンシャル G）で Metropolis に受理する。太陽は Y→X を光子ごとに代金 e_ph = G_X − G_Y を払って駆動する。エネルギーは q = 0.0005 kT の整数で、台帳（太陽の残り＋系のエネルギー＋経路ごとの熱）が毎観測で整数として閉じる。膜・細胞・群れの ID は核に無く、上位の単位は検出器の側で数える。

腕: 主は M-hi（非等方・高い供給 S = 0.004・一様な初期 (W,A,X,Y,M_0,M_1,M_2) = (30,9,6,6,3,3,3)）と M-lo（低い供給 0.0014）。対照は I-hi・I-lo（等方の M）、A-dusk（t = 20000 で日没）、R-cell（置いた細胞）・R-gap（欠けた細胞）、負コントロール NC-dark（太陽なし）・NC-norep（膜を作る斥力なし）・NC-noM（M を作れない）、選択の腕 SEL-M・SEL-I・SEL-0、台帳の較正 E-base・E-hotrot・E-nopay。

観測器（observerDetails）: 障壁の検出器 T（膜のサイト μ ≥ 0.5 → U1 膜の断片 → U2 膜で閉じた生きた内腔 → U3 群れ。段の数 n_T）と、M を見ない中身の検出器 C（活性サイト a ≥ 3 の有界な成分 → その群れ。n_C）。資格は被覆 f_cov = 0.5 と年齢 τ_age = 500 刻み。判定は W = [30000, 40000]（20000 刻みの腕は [15000, 20000]）の中央値。

妥当性検査: node selftest.js は 34/34 通過（S4 が再実行して確認。s4-analysis/selftest.out.txt）。φ の増分と数え直しの一致、台帳の閉じ、小さな箱の Boltzmann 分布（χ²）、壊れた触媒の検出、検出器の手組みの場（理想の泡・リング・厚い壁の滴・浸透の閾値）、追跡の筋書き、Worker と再開、決定性など。ただし、登録の正コントロールのうち 2 つが別の検査に置き換わっていた（§3.4）。

  • 素材より長く続く（登録の旗 selfMaint に当たる量。ただし記録の旗は構造上偽。§5.1②）: U1 の M で重み付けた年齢の中央値は W で M-hi 32700・32200 刻み、I-hi 3300・2600 刻み。M の化学的な滞在時間 τ_M は記録で 475〜477 刻み（M→X を入れて S4 が見積もると 344〜374。§5.1③）なので、非等方の斑点の素材の M は同じ個体のうちに約 70〜95 回入れ替わっている。等方の斑点も τ_M の 5〜10 倍は続くが、年齢の中央値が数千刻みで何度も落ちる（401 観測のうち 123〜126 回、非等方は 3〜10 回）——個体としての入れ替わりが非等方より 1 桁速い（図2b）。非等方の方が長い

3. 何をやったか

系（criteria.json の system。1回目と同じ）: 2 次元の三角格子 64×64・周期境界。サイトごとに種の数だけを持つ（W 水・A 自己触媒・X 資源・Y 廃物・M_0/M_1/M_2 向きを持つ膜分子。選択の腕だけ寄生 P）。1 刻み = 全サイトを無作為な順に 1 回ずつ訪れ、隣への移動・M の回転・同じサイトの中の反応（A が X から A と M を作る触媒とその逆、全種の Y への崩壊とその逆）を 1 粒子のエネルギーの変化（隣までの対の斥力と化学ポテンシャル G）で Metropolis に受理する。太陽は Y→X を光子ごとに代金を払って駆動する。エネルギーは q = 0.0005 kT の整数で、台帳が毎観測で整数として閉じる。膜・細胞・群れの ID は核に無く、上位の単位は検出器の側で数える。

腕: 主は M-hi（非等方・高い供給・一様な初期）と M-lo（低い供給）。対照は I-hi・I-lo（等方の M）・A-rand（無作為な初期）・A-dusk（t = 20000 で日没）・R-cell（置いた細胞）・R-gap（欠けた細胞）・NC-dark・NC-norep・NC-noM、選択の腕 SEL-M・SEL-I・SEL-0、台帳の較正 E-base・E-hotrot・E-nopay。

観測器: 障壁の検出器 T（膜のサイト → U1 → U2 細胞 → U3 群れ。n_T）と、M を見ない中身の検出器 C（有界な活性領域 → その群れ。n_C）。資格は被覆 0.5 と年齢 500 刻み。判定は W の中央値。

妥当性検査: node selftest.js は 41/41 通過（s4-analysis-r2/selftest.out.txt）。1回目の 34 項目に、M→X が核に在ること・Poisson の平均場が S_lo の生きた状態を再現すること・S_align の主軸・R-gap の初期状態が R-cell と違うこと・RP1/RP3 が値を返すこと・本番の長さで L1 が立つこと、などが加わった。ただし selftest は ④ の配線（§5.1①）・selfMaint の系譜の取り違え（②）・τ_M の数え方（③）・死因の分類器が呼ばれていないこと（⑤）を検査していない。

① 判定 ④ が「旗が定義されているか」で出ている（writer.js の judgmentsOf）:

7. 本家サブプロジェクトへの含意（候補として挙げるだけ。要件化しない）

  • 反発と触媒の格子化学（本件の母数）は、一様な初期から膜の段までを自発的に作り、閉じた区画は作らなかった。 膜の段は規則由来の 2 つの性質（選択的な障壁・向きのそろい）と、素材の 70 倍以上続く持続を持つ。非等方の膜分子は、閉じた区画ではなく「縁にそろって長く続く斑点」を作った。膜の断片と閉じた細胞の間の段差は、表の読みを登録どおりに直しても越えられなかった（少なくとも本件の斥力の強さ・密度・時間では）
  • 置いた細胞は壊れながらも同じ場所で閉じ直し、中身を周りへ播いた。 双安定の系では、区画は「代謝を閉じ込める器」より先に「生きた状態の種」として働く。閉じを壊した参照（R-gap）と閉じた参照（R-cell）の成り行きが区別できなかったのは、閉じた方が 100 刻みで破れたからで、閉じの効き目を問うには壁が先に持つ系が要る
  • 区画の無い系に寄生を足すと、1 万刻みで全体の代謝が崩れる（2 回の走行で同じ）。淘汰圧を区画の段へ繋ぐには、先に区画が要る
  • 低い供給でも、サイトの数の揺らぎが一様な生きた状態を支える（2回目でも組成が Poisson の平均場と 2% で合った）

8. 限界

  • リポジトリに入っていない生ログ: raw/run2/energy-ledger.jsonl（15.9MB）と raw/run2/timeseries.jsonl（5.6MB）は 1MB を超えるため .gitignore に列挙されており、ローカルにだけ在る。本レポートの時系列の数値・図2・図3・台帳の足し直し・L1 の当て直しはこの 2 ファイルから取った（1回目の raw/energy-ledger.jsonl・raw/timeseries.jsonl も同様で、図3 の1回目の値はそこから取った）
  • 原典の再現ではない（sourceFidelity）: どの版にも 2 次元の数値の母数が無く、斥力・G・速度定数・供給は登録が平均場で選んだ。受理関数（Metropolis）・更新の順序（逐次）・サイトあたりの粒子数（60）・台帳・寄生 P も原典と違う。原典の定性的な型（一様な初期から膜が分離し、閉じた膜が細胞を作る）が出なかったことは、原典の系について何も言わない。原典との忠実性を原典の数値で確かめることはできなかった
  • 登録した更新規則は詳細釣り合いを厳密には保たない（1回目の S4 の発見。§5.1④）。2回目もこの規則のまま走っており、駆動の無い窓での循環は残る。駆動のある腕の結果にこの循環がどれだけ効いているかは分からない
  • 判定が読めないもの: ④ の記録（配線の欠陥。登録どおりに読み直した）、膜の段の selfMaint の旗（系譜の取り違えで構造上偽）、遷移が「新（創発）」か（同じ理由）、E-hotrot の「J < −3 SE」（SE が生ログに無い）、細胞の死因（分類器が呼ばれていない）、H-strict の全て（L2 未形成）、RP2（S_align の帰無値。notImplemented）、形の分類・細胞ごとの f_P と内腔の X（未実装）
  • knob の感度は簡略版: 登録の「全 W 観測で knob ごとに追跡をやり直す」は実装されていない。S4 が当て直したのは被覆と年齢の閾値だけ（§4.5）
  • スナップショットは各走行 4〜5 時点: 置いた細胞の閉じ直しが同じ場所だったことは t = 2600 の 1 枚でしか確かめていない
  • τ_M の M→X の分は 1 時点の期待値の見積もりで、M→X の実際の件数は記録されていない
  • S_align の独立の再計算は記録と 0.00〜0.05 ずれ、原因を特定していない
  • SEL-0 の f_P の上昇の原因（1回目の S4 の見立て: 未触媒の k0 と崩壊の逆が A と P を 1 : 1 で作る）は、2回目でも確かめていない
