一行で言うと

事前登録した 16 マスのうち 14 マスが予測どおりで、外れた2マスは A2（色濃度＋サイズ）と A3（ユーザ例示の合成）の厳格判定である——両腕とも R と J* を held-out 5/5 シードで通しながら、第3条件 E_φ だけで落ちた（A2 は 1/5、A3 は 0/5）。機構は「復元した奥行きを隣接フレームで差分すると雑音が増幅し、奥行きを捨てた A0 より群れの分極度を悪く伝える」ことで、A2 の E_φ は 5シード中4シードで A0 より大きい。そして5つの写し方の順位を完全に決めていたのは、載せた奥行き情報の量ではなく 画面に残って検出された個体の割合であった——J* と検出率の Spearman は 1.000（5つの写し方。8腕でも 0.929）、これは S-52 が4次元で得た 0.97 の3次元版にあたる。ただし S-52 で最良だった手筋「潰す（正射影）」は S-51 では最下位である: 同じマークを 400 個重ねると塗り円が融合し、検出率 3.3% と全腕の最低になる。手筋の順位は次元をまたいで保たれず、保たれたのは「残存個体数が判定量を決める」という機構のほうである。あわせて、負コントロール①②が緩和を通り厳格を落ちるという事前登録の中心的予測は 2/2 で当たった（NEG1・NEG2 とも緩和 5/5・厳格 0/5）が、この厳格側は証拠ではなく定義上到達不能であったことを本レポートが検出した（自系 A0 の E_φ 基準線が 0.042〜0.051 で、要求する差 0.05 より小さい）。

何をやったか

題材

N=400 の3次元 boid（Reynolds 1987 の優先順位つき3規則、systemConstants 固定）を 1,600 ステップ走らせ、burn-in 800 の後に 40 ステップ間隔で 20 個の評価窓（各 4 フレーム）を取る。同一シード・同一ステップの同一の3次元配置を、5通りの写し方で 512×512 の RGB ラスタへ描き分ける:

腕写し方出所
A0正射影（半径 4 px の白円。z を一切使わない）参照点の床（親指示）
A1中央平面スライス（\z−z̄\≤ 6 のスラブだけを A0 と同一のマークで描く）ユーザ例示①
A2色濃度＋サイズ（高さ＝赤・奥行き＝青の濃さ、平面に近いほど大きい 1.5〜7.0 px）ユーザ例示②③

A4二面表示（256×256 の左 xy と右 xz。1個体が2マーク）S1 が足したもの

負コントロールは3種: NEG1 独立ランダム歩行（相互作用だけを壊す）／NEG2 静止した球殻（運動だけを壊す）／NEG3 属性シャッフル（系は壊さず、描画属性と z の対応だけを壊す。周辺分布・マーク位置・重なり構造は A2 と厳密に同一）。いずれも A2 の描画で測る。8腕すべてが held-out 5 シードで走っている（per-run.json 80 行 = 8 × 5 × 2 復号器。欠けた腕・欠けたシードは無い）。

観測器（判定の語彙）

復号器は2つ。D1 pixelLocal（判定の正） は描画済みピクセルだけを入力に取り、個体数も個体リストも与えられずマーク検出から始める。D2 preRasterGrouped（上限） はラスタライズ直前の描画レコードを個体ごとにグループ化して受け取る。D2 − D1 がラスタライズ・検出・対応づけが壊した分である。

秩序変数は3つ: R（隠れ座標 z の復元度。1 − MSE/MSE_null、帰無値 0）／J\*（3次元 k 近傍の保存度、k=10、無作為一致で補正済み）／E_φ（分極度の伝達誤差 |φ_rec − φ_true|）。判定は2本: 厳格 = R > 0.05 かつ J* > 0.05 かつ E_φ < E_φ(同系・同シードの A0) − 0.05 を held-out 5 シード中 3 本以上／緩和 = R > 0.05 のみ。『復号できる』と『群れが読める』は別であるという区別を、この2本の差として作業定義にしてある。

妥当性検査の結果

node apps/alife-sketches/s51-boids-3d-projection/selftest.js は 36 項目通過 / 0 項目不通過。内訳は criteria との整合（11）、保存則と有限性（5）、同一シードでのハッシュ一致（4）、K-12「古い状態を見ていないか」（2）、正コントロール3種（6）、負コントロール③（1）、J*・φ の構成上の性質（3）、ridge の解析的検算（1）、A4 の D1/D2 ギャップ（3）。

ただし、selftest に無い登録項目が1つある。 criteria.json の system.note は「群れになっていることは positiveControls ではなく φ_true > 0.5 という前提条件として selftest で確かめ、満たさなければ S2 が親へ申し送る」と登録しているが、selftest が φ について検査するのは「φ は [0,1] の範囲」だけで（出力された値は 0.157）、φ_true > 0.5 の検査は存在しない。φ_true は run.js の E_φ 計算の中で毎フレーム計算されているが、どの生ログにも書き出されていない。本レポートが系そのものから計算し直した結果は下の事後解析の節に置く（結論: held-out 5 シードのうち前提条件を満たすのは 2 本）。

A2 が厳格を通った唯一のシード 510203 は、A2 の E_φ が下がったシードではなく、基準線 A0 の E_φ が跳ね上がったシードである（0.084〜0.189 に対して 0.396）。すなわちこの 1/5 は腕の性質ではなく基準線の性質である。

機構は登録の定義そのものの中にある。E_φ の φ_rec は復元位置の隣接フレーム差分 (p̂(t+1) − p̂(t))/dt から作る。A0 は ẑ を定数（z̄_cal）に固定するので v_z 成分が厳密に 0 になり、単位速度が xy 面内に留まる。A2/A3 は ẑ を R ≈ 0.43 の精度で復元するが、誤差の RMS は z の標準偏差の約 0.76 倍（世界単位で約 11）あり、これを 1 ステップで差分すると z 方向の見かけ速度が真の速さ（v_max = 1.0）の 10 倍以上になる。単位ベクトルがほぼ ±z のランダム方向を向き、φ_rec が潰れる。奥行きを復元したほうが、奥行きを捨てるより群れの秩序を悪く伝える——これは登録の E_φ が「復元値を微分して使う」形をしていることの帰結であり、写し方の性質ではない。

負コントロールの3マス — 中心的予測は 2/2 で当たった。ただし片方は到達不能だった

登録の中心的予測は「NEG1・NEG2 は緩和を通り、厳格を落ちる」であり、_comment はこれを「『復号できる ≠ 群れが読める』の中心的な証拠」と呼んでいる。実測はそのとおりである: NEG1 は緩和 5/5・厳格 0/5、NEG2 も緩和 5/5・厳格 0/5。しかも 群れが一切存在しない系のほうが、群れがある系より R が高い（NEG1 0.801・NEG2 0.928 対 A2 0.427）。緩和規則は3次元構造の有無すら区別せず、符号化の質と検出のしやすさだけを測っているという登録の言い分は、2つの独立な壊し方から支持された。

ただし厳格側は証拠ではない。 本レポートが自系 A0 の E_φ 基準線を計算し直したところ（下の事後解析）、

  • NEG1（独立歩行）の自系 A0 の E_φ = 0.042〜0.046
  • NEG2（静止球殻）の自系 A0 の E_φ = 0.044〜0.051

であり、厳格が要求するのは E_φ < 基準線 − 0.05、すなわち E_φ < −0.008 〜 +0.001 である。E_φ は絶対値なので非負であり、NEG1 の 5 シードすべてと NEG2 の 4 シードで、この条件は値に依らず満たせない。S1 は determinedByDefinition を 4 マス（A0×2・A4×2）に付けたが、NEG1×厳格・NEG2×厳格も同じ意味で定義上決まっていた——「群れが無い系では φ_true が雑音水準 1/√N = 0.05 であり、基準線もその水準になるので、0.05 の差を要求する条件は原理的に満たせない」。K-53 の欄はこの 2 マスを取りこぼしている。

NEG2 はさらに強い形で決まっている。 core.js の staticShellFrame は位置ジッタを configSeed のみから作る（コメントに「フレーム間でも固定」と明記）ので、窓内の 4 フレームで位置がビット単位に同一である。したがって復元位置の差分は厳密に 0、φ_rec = 0 となり、E_φ = φ_true が復号器にも写し方にも依らず成り立つ（実測: NEG2 の E_φ は D1 と D2 で同一の 0.0457 / 0.0438 / 0.0511 / 0.0465 / 0.0449 で、自系 A0 の値と小数第4位まで一致する）。これは登録の whatSeedChanges ②「負2 ではシードはジッタしか変えない。複数シードの一致は現象の証拠ではない」が予告したとおりであり、K-36 の「値の一致による同一性の主張」に当たる。

S2 が申告した6件の独立検証

#S2 の申告本レポートの検証
1マーク検出の「同点は走査順」を平坦域全体へ拡張する必要があった支持する。 observer.js は塗り円の同値連結成分を1点（重心）へ潰す。登録文言（単一画素の同着）どおりでは塗り円1つから数十の極大が出るのは幾何から明らかで、これは仕様の欠落であって実装の逸脱ではない。ただし代表点を重心にしたこと自体が正コントロール[0]の数値を動かしている（次項）
2正コントロール[2]の半径は 1px ではなく 3px が要った支持する。 controls.json に注記つきで記録され、R = 0.999991 で通っている。登録値のままなら検出率 72% で、この対照が意図する「回帰段の下限保証」が検出段の脆さと混ざる。変更の向きは対照を甘くする側ではなく、対照の意味を保つ側である
3正コントロール[1]は構成を変える必要があった（層間 5.7px → 20×20 格子で 25.6px）支持する。 selftest が「疎な3D格子: screen 上の最小相互距離が 12px 以上 min=25.60px」を機械検査している。R = 0.999993・検出率 1.000
4E_φ の基準線を系ごとに計算する必要があった支持する。 run.js の a0ReferenceEphiFor が SYSTEM_KEY で flock / randomwalk / staticshell を分ける。主たる群れの A0（E_φ 0.084〜0.396）を流用すると NEG1（0.022〜0.027）・NEG2（0.044〜0.051）が厳格を誤って通ることを、本レポートが計算し直した基準線から確認した
5NEG1 が小規模走行では厳格を通ることがある。本番規模での結果は S4 が決める本番規模では通らない。 NEG1 の厳格は held-out 5 シードすべてで否。しかもこれは「大きな規模では予測どおりになった」ではなく、上で見たとおり条件が原理的に満たせない。S2 が小規模で見た通過は、基準線側の推定が小標本で揺れたときだけ起きうる現象である

S-52（4次元 boid の写し方）と並べる

S-52 の S4 が書いた比較の作法（reports/main.md の「S-51 と並べて比べるための作法」）に従う。

作法① O1（位置復元率）の生値は比較禁止 → 本スケッチでは比が定義できない

S-52 の指示は「帰無値 R_chance が d=3 と d=4 で 16.6 倍違うので R/R_chance で比べよ」である。S-51 の R はこの形の量ではない。 S-51 の R は 1 − MSE/MSE_null という分散説明率で、orderParameters が「理論的な帰無値 0 を持つ（画像を見ずに定数 z̄_cal を返す予測器がちょうど 0）」と登録している。帰無値が厳密に 0 なので R/R_chance は定義できない（0 除算）。したがって S-51 の R と S-52 の O1 は、比の形にしても並べられない。 並べられるのは次の作法②だけである。

作法② J*（近傍保存）は帰無値が d に依らないので直接比較できる

S-52 の O2 は生の J_6（帰無 0.0323）、S-51 の J* は無作為一致で補正済み（帰無 0）である。**S-52 の効果量を J* 尺度へ直すには (1 − 0.0323) で割ればよい**（差の量なので ×1.0334）。

逆転の機構は、どちらのスケッチでも同じ説明で尽きる。 S-52 の 潰す は「軸を丸ごと捨てる」ので個体が画布の外へ出ず、残存個体数が最大になる（S-52 の透視は 29〜57% を画布外へ出し、断面は 85% を描かない）。S-51 の A0 は同じく全個体を描くが、全マークが同一の半径 4 px の白円なので、重なった円が1つの極大へ融合し、検出率 3.3% と 8 腕中の最低になる。すなわち 同じ手筋が、片方では残存率を最大にし、もう片方では最小にする。

したがって「同じ手筋が3次元と4次元で同じ向きに効いたか」への答えは: 断面とチャネルは同じ向き、潰すは逆向き。ただし機構のほうは両方で同じである——「主判定量を決めているのは載せた情報量ではなく、画面に残って数えられた個体の数」。S-52 が Spearman 0.97、S-51 が 1.000。手筋の順位は次元をまたいで移植できないが、順位を作っている機構は移植できる。

注意: S-51 の A0 の残存率が低いのは写し方の性質ではなく、写し方と検出器の組み合わせの性質である。S-52 の残存率低下（画布外・非描画）は復号器を替えても回復しないが、S-51 の A0 の融合はマークを小さくするか、個体ごとにわずかでも見た目を変えれば解消する。実際 D2（検出を通さない上限）では A0 の J* が 0.374 まで戻る。

作法③ 中央値どうし・平均どうしの2組を作る

S-52 は「登録した二段中央値では 13/16 腕が 0 に落ちるので、(i) 同じ集計どうし (ii) 同じ補助値どうしの2組で同じ結論が出るかを見よ」と指定する。

S-51 には二段中央値に当たる集計が無い。 J* はフレーム内で全 N=400 個体を平均し（computeJStar は未検出を 0 として N で割る）、フレームを平均し、シードを平均する。個体レベルの中央値を取る段が存在しないので、S-52 の床（統計量の離散性による 0 への張り付き）はそもそも起きない——実際 S-51 の J* は 8 腕すべてで 0 でない値を取る。

作れるのはシード段の中央値版だけである。上の事後解析①のとおり、平均版と中央値版で 5 腕の順位は 1 つも変わらず、検出率との Spearman はどちらも 1.000 である。 したがって S-52 が求めた「2組で同じ結論が出るか」は、S-51 が作れる範囲の2組では同じ結論になる。ただしこれは S-52 が心配した種類の頑健性（個体レベル集計の選択）を検査したことにはならない。

作法④ 腕名は共有できない／検出率を直接比べない

S-51 は 3→2 の一段（5択）しか持たないので、S-52 の 16 腕と対応する腕は無い。比較は上の主効果だけで行った。検出率（S-52 の O3）も直接は比べていない——S-51 の検出率は 512×512 に 400 個体、S-52 は 256×256 に 96 個体で、画素あたりの密度も検出器も違う。

本家サブプロジェクトへの含意（候補として挙げるだけ）

  1. 「見えている」と「読み取れる」を分ける作業定義が、負コントロールで実際に分離した。 群れが一切存在しない系（NEG1）と、運動が一切無い系（NEG2）の両方が、「隠れ座標が復号できる」判定を 5/5 で通した。復元度の高さは、系に構造があることの証拠にならない。
  2. 人工生命の可視化において、同一のマークを多数重ねることは情報を捨てることと等価になりうる。 A0 は z 以外の情報を全部持っているのに、個体が数えられない（対応 8.5%）。個体を識別可能にする最小の差異（大きさ・色）が、奥行きの符号化より先に効いている。
  3. 奥行きを復元してから微分すると、群れの秩序変数は復元しないより悪くなる。 位置の復元度と、位置から作った速度の秩序変数は、独立に扱う必要がある。

限界（この実験が言えないこと）

  • 人間の可読性については何も測っていない。 本サブプロジェクトは人間に見え方を訊く手段を持たない。厳格規則が言うのは「この固定した復号器が、3つの量を正射影より良く取り出せた」ことだけで、人間の知覚についての主張を一切含まない。viewer.html は理解のためのもので、測定には入っていない。
  • A4 が落ちたことから「二面表示は読みにくい」とは言えない。 言えるのは「この復号器は二面表示を読めない」だけである（ceilings[0]・decisionRule が事前に指定）。D2 では R = 1.0000 である。同じく A1 が落ちたことから「スライスは読みにくい」とも言えない——スライスは情報をマークの特徴ではなく描かれた／描かれなかったという二値に置く写し方で、登録した復号器はその置き場所を読まない（未検出個体に z̄_cal を入れる規約による）。
  • 出典が二段である。 boid の力学は Reynolds 1987 の本文（61,800 字を抽出して直接確認）の再現だが、具体的な数値パラメータは原典が与えておらず S1 が選んでいる（systemConstants、および3規則それぞれの強さ k_sep/k_match/k_cent・分離則の床 eps_avoid・初期配置の球半径は S2 が選んでいる）。写し方と可読性の測り方の側は原典がまったく無く、S1 が起こした設計である。 work/2026-09-17-4d-visualization-sources.md の調査結論のとおり、「描画された画像から元の状態を復号する」評価法に確立した先行は見つかっておらず、引用のある既存物ではなく、こちらが作り込んでいる空白である。既存の投影品質指標（trustworthiness・continuity・co-ranking・stress）は埋め込み座標から測るもので画素を経由しないため、S-51 の J* は近い発想でありながら既存指標との比較可能性を持たない。借用した定数（優先順位・逆2乗則・視野 300 度）のうち 視野 300 度は Reynolds 自身が boids へ与えてはいない（実鳥の観測からの流用であることを borrowedConstants が明記している）。
  • 系が登録した前提条件を満たすのは held-out 5 シード中 2 本である（φ_true > 0.5）。selftest はこの前提を検査していない。「群れが読める」という語を使う場面では、5 本のうち 3 本は登録の意味で十分な群れではない。
  • 厳格規則は本走行で判別力をほとんど持たなかった（40 走行中 1 走行のみ通過、しかもその 1 本は基準線側の変動による）。負コントロール2種の厳格不合格は、証拠ではなく定義上の帰結である（自系 A0 の基準線 0.042〜0.051 < 要求する差 0.05）。
  • **厳格規則の第2条件 J\* > 0.05 は、個体が検出されれば奥行き情報が無くても通る（A0 の D2 で 0.374、対応を壊した NEG3 の D1 で 0.149）。この閾値は登録の雑音床の見積もり（無作為部分集合の 0.003）に基づいており、比べるべき帰無（正射影しか知らない観測者）に対しては立てられていない**。
  • 上限の記録は判定量の内訳として読めない。 量子化の記録は2つの量子のうち小さいほうだけを数え（1.07% 対 31.07%）、検出漏れの記録は判定の母集団の 1% しか数えず（A1 ではその 1% が非代表）、正コントロール①は登録の許容（2 倍）ではなくコードの許容（4 倍）で合否を出し、実測はその間にある。
  • 母集団感度の対照は A1 の1シードしか無いので、登録が予告した「分母の選択が腕の順位を変える」かどうかは本走行からは判定できない。A1 について言えるのは、予測した向き（落とすと A1 が最高得点になる）とは逆に動いたことだけである。
  • ノブは代表1条件（A2・較正 510101・評価 510201）でしか振っていない（knob-sweep.json の注記どおり）。腕をまたいだ感度は測られていない。
  • seedSplit に漏れは無いが、登録が求めた「較正と評価を混ぜた場合の値」は生ログに無いので、分割が何点ぶんの上振れを防いだかは数として示せない。
  • 時間チャネルを使う写し方（wobble・トレイル・点滅周期）と透視投影は、登録の時点で落としてある（ceilings[3]）。本スケッチが測ったのは静的なチャネルへの写し方だけである。
  • S-52 との比較は主効果1組どうしであり、標本は S-51 側が 3 手筋・5 シード、S-52 側が 4 手筋・3 シードである。 統計的な検定はしておらず、向きの一致・不一致を述べているだけである。S-51 の R と S-52 の O1 は、帰無値の性質が違うため比の形にしても並べられない。
