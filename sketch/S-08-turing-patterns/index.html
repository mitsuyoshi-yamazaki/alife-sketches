一行で言うと

拡散は単独では必ず均すのに、2 種の拡散の速さの比がちょうど 4.0 を超えた瞬間から模様が立つ。 この 4.0 は当てはめた値ではなく d_c = A²/(√B−1)² という閉じた式で、掃引は d ≤ 4.0 の 20 レプリケートで検出率 0%、d ≥ 4.25 の 28 レプリケートで 100%——理論の閾値をまたいだ次の点で切り替わった。選ばれた波長も理論値の 0.92〜1.02 倍に収まった。同時に、その「帰無値 1.0 を持ちスケールを選ばない波長比」は、何も育っていない安定な系（振幅 10⁻¹⁴）でも 0.94〜0.98 を返した——理論から出る帰無値を持ち、理論から出る予測値に当たっていてなお、その量は単独では何も判定していない。

何をやったか

題材と、そこにある逆説

Turing (1952) が示したのは、それ自体は均す働きしか持たない拡散が、2 種類あって速さが違うと、逆に模様を作るということである。本スケッチはこれを Brusselator（Prigogine & Lefever 1968）で実装した:

∂u/∂t = Du ∇²u + A − (B+1)u + u²v
∂v/∂t = Dv ∇²v + Bu       − u²v

逆説であることは 2 つの事実から来る:

  1. 拡散だけなら必ず均す。 ∂u/∂t = Du∇²u の解では、あらゆる波数の振幅が exp(−Du k² t) で減る。増える波数は 1 つも無い
  2. 反応だけでも一様状態は安定。 下で導くとおり tr J = B−1−A² = −8 < 0、det J = A² = 16 > 0。A=4, B=9 では擾乱は振動しながら減衰する

安定な反応に、均すだけの働きを 2 つ足すと、特定の波長だけが育つ。

線形安定性解析（自分で導いた）

① 一様不動点。 f = A − (B+1)u + u²v、g = Bu − u²v とおくと f + g = A − u。よって定常には u₀ = A、そこから g = 0 より v₀ = B/A。厳密。

② Jacobi 行列。 不動点上で

f_u = −(B+1) + 2u₀v₀ = −(B+1) + 2B = B − 1
f_v = u₀² = A²
g_u = B − 2u₀v₀ = B − 2B = −B
g_v = −u₀² = −A²

J = [[ B−1,  A² ],
     [ −B ,  −A²]]          tr J = B − 1 − A²        det J = A²(B−1)·(−1) + A²B = A²

det J = A² > 0 は常に成り立つので、拡散が無いときの安定条件は tr J < 0、すなわち B < 1 + A²。A=4, B=9 では 9 < 17 で成り立つ（tr J = −8）。したがって以降に現れる非一様構造は、拡散を入れたことによってのみ生じる。

③ 拡散を入れる。 擾乱を exp(σt + i k·x) と置くと、σ は det(J − k²D − σI) = 0 の根。q = k² として

σ² − tr(q) σ + h(q) = 0

tr(q) = tr J − (Du + Dv) q                        ← 常に tr J より小さい = より安定
h(q)  = det(J − qD)
      = Du Dv q² − (Dv f_u + Du g_v) q + det J
      = Du Dv q² + (A² Du − Dv(B−1)) q + A²

ここが要点である。 拡散は tr(q) を必ず下げる（安定化する）。不安定化が起こりうるのは h(q) < 0 になる経路だけで、その 1 次の係数 −(Dv f_u + Du g_v) が負にならなければならない。f_u = B−1 > 0（u は自分を増やす）、g_v = −A² < 0（v は自分を減らす）なので、Dv が正の自己増幅に、Du が負の自己減衰に掛かっている。負にするには Dv のほうを大きくするしかない。

④ 等しい拡散では決して起きない。 Du = Dv = D を入れると

h(q) = D² q² − D·(f_u + g_v) q + det J = D² q² − D·tr J·q + det J

tr J < 0・det J > 0 なので係数がすべて正。したがって q > 0 で h(q) > 0 が常に成り立つ。「拡散が 2 種類あること」では足りず、「速さが違うこと」が要るという主張は、この 3 行で尽きている。

⑤ 閾値。 h(q) は上に開く放物線で h(0) = A² > 0。最小値が負になる条件は

[Dv(B−1) − A² Du]² > 4 Du Dv A²
⇔ Dv(B−1) − A² Du > 2A √(Du Dv)
⇔ (B−1) − A² r² > 2A r          （r = √(Du/Dv) と置いた）
⇔ B > (1 + A r)²

したがって B_c = (1 + A√(Du/Dv))²。これを拡散比について解くと

√B = 1 + A √(Du/Dv)  ⇒  d_c = Dv/Du = A² / (√B − 1)²

A = 4, B = 9 では d_c = 16 / (3−1)² = 4.0（厳密）。 掃引はこの値をまたぐように組んだ。

⑥ 選ばれる波長。 臨界ではちょうど h(q_c) = 0 なので

q_c = [Dv(B−1) − A² Du] / (2 Du Dv) = 2A√(Du Dv) / (2 Du Dv) = A / √(Du Dv)

λ_c = 2π / √q_c = 2π (Du Dv / A²)^(1/4)

λ は (Du·Dv)^(1/4) に比例する——拡散係数を両方 s 倍すれば波長は √s 倍になる。これが拡散スケール掃引で検証した予測にあたる。臨界を超えた点では、最も速く育つ波数（σ(q) を最大にする q）を予測値とした。閉じた式は無いが、分散関係の走査で一意に決まり、当てはめる自由度を 1 つも持たない。

観測器（実装より先に固定した）

理論が閾値も波長も与えるので、スケールの選択を含まず帰無値を持つ秩序変数が最初から手に入る（K-10）。ただし K-14 により帰無値は偽陽性を防がないので、主は最初から連言にした:

連言（主）上の 4 つすべて＋値が有限であること——

観測波長は環状スペクトルの 1 次モーメントで測り、頂点（argmax）は副次として併記した（K-9）。

測り方は本番前に一度差し替えている（criteria.json rev2、ハッシュは差し替え後に確定）。初版は頂点を主にしていたが、妥当性検査で単一の実現では argmax が環ごとの揺らぎに支配されることが分かった——拡散だけで粗大化する対照系では、真の波長が滑らかに伸びているのに argmax は n*=16 → 9 → 4 と飛び飛びに留まり、隣り合う時刻で偶然同じ環に留まると lambdaDrift まで 1.00 を返す。8 区間中 4 区間でこれが起きた（selftest が固定してある）。原因は環 n に含まれるモード数が 2πn しかないことで、1 次モーメントは全ての環を重みつきで使うので揺らぎに強い。掃引を一度も走らせる前の修正である。

妥当性検査（35 項目・全通過）

本題材に固有の要点が 3 つある。

① 発散を模様と誤認しないこと。 陽解法は dt ≤ dx²/(4D) を破ると発散し、発散した場を絵にすると模様に見える。dt = 0.05（CFL = 6.40）で実際に走らせ、finite = 0 が立って観測量が一切報告されないことを検査した。本番の全 63 レプリケートで CFL は 0.064〜0.400 に収まり、発散は 0 件。

② 理論と数値が同じ系を指していること。 単一波数の擾乱を固有ベクトルの向きに入れ、振幅の成長率を分散関係と突き合わせた:

入れた波数実測の成長率格子の理論値連続体の理論値
k = 1.374（不安定）1.71301.71841.7258
k = 2.945（安定）−1.2036−1.2014—
k = 1.388（斜め）1.72031.7258—
k = 1.374, d=2（閾値未満）−1.9761−1.9683—

同じ波数が、拡散比を閾値の下へ動かすだけで成長から減衰へ転じる。 これが逆説の中身そのものにあたる。

③ 核の検算（K-12）。配列を入れ替える速い更新と、毎回まるごと複製する素朴な実装が 40 ステップ後にビット単位で一致した（ここが崩れると Jacobi でなく Gauss-Seidel になり、しかもそれらしい絵が出る）。拡散だけなら総量が機械精度で保たれ（相対誤差 7×10⁻¹⁶）、一様不動点は 200 ステップ後もずれ 0。観測器は毎回現在の場から測り直し、同じシードで完全に再現した。

検出器の側は、既知の波長の縞（軸平行・30°・53°）を 0.01〜0.76% の誤差で返し、Parseval 等式（スペクトルの総パワー = 実空間の分散）が 10⁻⁹ 以内で成り立った。

事前登録した予測は当たった——「d ≤ 4.0 の全シードで振幅 0.05 未満、d ≥ 4.5 の全シードで 0.05 以上」。実際には d = 4.25 で既に全シードが検出しており、観測された切り替えは理論値 4.0 の直上にある。掃引の刻みで言えば、不安定になると理論が言った次の点で、実際に切り替わった。

  • d = 4.0 ちょうどは σ_max = −3×10⁻¹⁰（数値的に厳密な 0）で、振幅は初期擾乱 5.8×10⁻⁴ から 5.7×10⁻⁵ へわずかに減った。臨界の 1 モードは育ちも減りもせず、他は減る——理論どおりである
  • 規模（K-6）: 検出が始まる d=4.25 での模様は、振幅（変動係数）0.263、u は 4.0 を中心に約 2.6〜5.6 に振れ、箱（128×128）に約 29 本の波が入る。d=8 では振幅 0.699、u は 0.66〜9.78 まで振れる。正コントロール（手で組んだ縞）と同じ規模ではなく、系そのものの大きさに達している
  • シード間のばらつきは極小（d=8 の 4 シードで振幅 0.6983〜0.6995、波長 4.250〜4.260）。閾値の位置は 1 シードでも決まる

2. 波長は理論値に当たった

不安定な全ての d で |λ比 − 1| ≤ 0.35 を満たした（実測 0.924〜1.017）。当てはめた自由度は 1 つも無い——λ理論はパラメータだけから決まる。

頂点で測った副次の比は 0.962〜1.031 で、主（1 次モーメント）との食い違いは最大 4.1%。事前登録した「15% 以上食い違ったら測り方に依存すると報告する」規則には触れなかったので、結論は測り方に依らない。

閾値の直上（d = 4.25〜6）で比は 1.00〜1.02、深く入るほど（d = 8, 10, 12）0.96 → 0.94 → 0.92 と下がる。理論の λ 自体は 4.38〜4.54 と 4% しか動かないのに対し、実測は 4.42 → 4.20 と短くなる。深く入るほど実際に選ばれる波長は線形の最速モードより短い。

  • lambdaDrift（帰無値 1.0）も同じ 2 系を通す（閾値未満で 1.000、等拡散で 1.000）。減衰しきった場では波長が動かないのは当然である
  • patternAmplitude（帰無値 0）を通す偽物も 2 種類——粗大化（0.123）と並べ替え（0.699）
  • peakInterior は最も弱かった。偽物②③④⑥のすべてを通した

落とせたのは 4 つの連言だけである。 偽物③は振幅・内側の頂点・波長比の 3 つを通り、lambdaDrift だけが落ちた（1.542）。偽物⑥は内側の頂点・波長比・drift の 3 つを通り、patternAmplitude だけが落ちた。この 2 つは互いに逆向きの偽物で、どちらか一方だけを想定した観測器では必ず取り逃す。

偽物③については、波長が選ばれていないことの積極的な証拠も取った——拡散だけの場の波長は時間とともに λ = 1.98 → 2.65 → 4.09 → 6.07 → 8.75 → 12.43 → 17.66 → 25.61 と伸び続け、連続する比は 1.34, 1.54, 1.48, 1.44, 1.42, 1.42, 1.45 で √2 = 1.414 へ収束する（λ ∝ √(D t)）。一方 Turing の波長は t = 10 から t = 100 まで 4.19 → 4.26 と 1.6% しか動かない。「選択」と「粗大化」は、波長そのものではなく波長の時間依存で分かれる。

5. 予測が外れた点

負コントロール④（並べ替え）について、peakInterior が落ちるという事前登録した予測は外れた。 白色雑音の環状スペクトルは環のモード数のぶん n に比例して増えるので頂点は端（n = nmax = 128）に来るはずだったが、実際の頂点は **n\* = 121** で、登録した内側判定（2 ≤ n* ≤ nmax − 2 = 126）を通ってしまった。この偽物を落としたのは lambdaRatio（0.339）だけである。

登録した閾値は「端から 2 環以内」だったが、揺らぎは端から 7 環ぶん内側に頂点を置いた。「端に張り付く」という直感を離散的な判定に翻訳する段で、幅の見積もりを誤っている。 連言としての判定は変わらないが、peakInterior 単独の弁別力は登録時に想定したより弱い。

事後解析（事前登録していない）

以下は掃引の後に気付いたもので、上の結論には使っていない（K-11）。

反応項が恒等式を 1 本持っている。 f + g = A − (B+1)u + u²v + Bu − u²v = A − u と、u²v が厳密に打ち消し合う。したがって

d/dt ⟨u + v⟩ = A − ⟨u⟩

が厳密に成り立ち、定常状態では u の空間平均が厳密に A になる——模様が立っていても。生ログを見ると d=8 の定常状態で ⟨u⟩ = 4.0000（u は 0.66〜9.78 まで振れている）。妥当性検査に 1 項目として追加し、⟨u⟩ = 3.99996998 を確認した（掃引の後に足した検査であり、事前登録した解析ではない）。

成長は理論の速さで立ち上がり、5 時間単位で飽和する。 d=8 の時系列で、振幅の対数微分は t=2→3 で 1.619（理論 σ_max = 1.731）。t=5 で 0.373、t=7 以降はほぼ 0。飽和後 t=10 から t=100 までの 90 時間単位で振幅は 0.673 → 0.698 としか動かない。模様は立ち上がりがすべてで、そのあとはほとんど何も起きない。

本家サブプロジェクトへの含意（候補として挙げるだけ。要件化しない）

  • 「帰無値を持つ観測量」は、観測器の設計の到達点ではなく出発点にすぎない。 本スケッチの lambdaRatio は、帰無値も予測値も理論から出るという点で S-02・S-06 のどの観測量より強い立場にあったが、振幅 10⁻¹⁴ の「何も無い」系で 0.98 を返した。理論が予測値まで与える題材ですらこうなるなら、理論が無い題材で「帰無値があるから大丈夫」とは言えない
  • 偽物は 2 方向から来る。 「構造があるが目当てのものではない」（粗大化・並べ替え）と「目当ての量は合っているが何も起きていない」（閾値未満）。後者は S-06 では出ていなかった形で、量の値だけを見る観測器はこちらを落とせない。規模（振幅）と形（波長）は必ず両方測る
  • 「選択」と「単なる構造」は、量そのものではなく量の時間依存で分かれる。 粗大化は λ ∝ √t、選択は λ = 一定。時間について止まっているかを見る観測量は安く、強い（長さのスケールを選ばない）

限界（この実験が言えないこと）

  • 言えるのは Brusselator についてだけである。 閾値 d_c = A²/(√B−1)² と λ ∝ (DuDv)^(1/4) はこの反応項に固有で、Gray-Scott や FitzHugh-Nagumo では別の式になる。「2 種の拡散速度が違えば模様が出る」という一般命題を検証したわけではない——検証したのは「ある系で、線形理論が指した点で実際に切り替わる」ことである
  • 原典の数式は照合できていない。 Turing (1952) の PDF は OCR のテキスト層を持ち散文は読めたが、数式はほぼ復元できない（§9 の「chemical wave-length」の式 (9.3) も本文中の参照しか読めず、式そのものは崩れている）。読めた範囲で確認できたのは概念の一致だけである——「環の波長は環の周長に依るが、環の寸法に依らない『化学的な波長』がある」「ピークの数は環の周長を化学的な波長で割って得られる」という記述が本文にあり、波長が系の大きさではなく反応と拡散だけで決まるという本スケッチの前提と一致する。Brusselator の閾値の式は自分で導いたものであり、導出後に文献検索で B_T = (1 + A√d)² という同形の式を確認した（実装と事前登録の後である）
  • 観測は定常状態の 1 時点と中間時点だけである。 模様の種類（縞か斑点か）、欠陥の数、境界条件の影響、初期条件依存性は測っていない。d が大きいほど波長が短くなる傾向は観測したが、その原因（Eckhaus 帯・高調波・振幅の非線形飽和）は切り分けていない
  • 格子の細かさは 1 通りしか本番で試していない（dx = 0.5）。拡散スケール掃引が実質的に「波長あたりの格子数」を 4.4〜17.7 個で振ったことになり、8 個を下回ると連続体理論からずれることは示せたが、同じ物理条件を 2 通りの dx で走らせる直接の検査は本番に含めていない（妥当性検査では離散ラプラシアンの誤差が O(dx²) で減ることまで確認した）
  • 絵が意味のあるものに見えるかは確認できていない（method §3 の既知の弱点）。viewer.html が呼ぶ API が核に実在することは機械検査したが、配色とレイアウトはユーザが最初に開いたときに初めて分かる
