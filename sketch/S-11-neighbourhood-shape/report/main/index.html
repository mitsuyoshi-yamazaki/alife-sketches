一行で言うと

近傍の期待次数を 6.03 に固定したまま「形」だけを変えると、報告される転移点が 52.8% 散る。同じ配置に対して形を円に固定したまま期待次数を 2 から 16 へ 8 倍に振っても、散らばりは 5.7% にしかならない。差は 9.3 倍で、Openshaw (1983) の「分け方の自由度のほうが数の自由度より効く」が本系で成り立った。 そして同じ形のノブをポアソン配置へ振ると値は 0.024 しか動かない（実系では 4.933）。比 0.005 なので、これは観測器の恣意性ではなく系の構造である（K-19）。

何をやったか

なぜこの回か

S-10 の文献調査が、S-02 の「連結半径を 2.0 から 2.5 に変えると結論が反転する」に MAUP の scale effect という既存の名前を与えた。同時に Openshaw (1983) の MAUP は2成分あることが分かった:

成分中身既作スケッチ
scale problem区画の数を変えるS-02 が連結半径で振った
aggregation problem数を固定して分け方を変える10本とも1本も振っていない

そして Openshaw 自身が「分け方の自由度のほうが数の自由度より効く」と書いている。本サブプロジェクトは危険を過小評価している可能性があった。本スケッチはその一点を潰しにいく。

系（S-02 の生データは使い回していない）

混雑した所で速さが落ちるだけの走行・転回粒子。トーラス 60×60、N=1200（ρ=1/3）、2000 ステップ:

v_i = v0 · exp(−λ · n_i / n0)      n_i = 半径 R=2.4 内の粒子数,  n0 = ρπR² = 6.03

引力も結合も無い。 遅い所に長く留まればさらに混む、という循環だけで塊ができる（MIPS）。 平均場では d ln v / d ln ρ = −λ·(n/n0) なので、λ > 1 が自己集積の条件になる。この 1.0 が理論側の参照点（A4）である。制御変数は λ。

核の側には「細胞」「膜」「遺伝子」「個体」「触媒」「適応度」「生きている」という語も概念も無い。あるのは粒子・向き・速さ・近傍・グラフ・次数・辺だけである（格子の区画も cell ではなく bin と呼んでいる）。

ノブ: 観測器が使う近傍の「形」。力学は一切変えない

同じ一つの配置に対して、近傍の定義だけを差し替える。期待次数を揃えないと、形の効果と次数の効果が交絡するので、まず揃える。揃える先は系の相互作用核 ρπR² = 6.0319 から借りた（K-10「粒度を系から借りる」）。較正はポアソン参照集団の上だけで行い、実系のデータは見ていない。

形定義ポアソンでの達成次数

square軸に沿う正方形（Moore 近傍の連続版）。面積は円と完全に同一6.042

観測器（事前登録。ただし rev 2 へ差し替えている）

秩序変数はすべて同じ N・同じ形のポアソン参照集団（16 本）に対する比にした。帰無値は 1.0 である。

  • degreeExcess = 平均次数の比
  • edgeLenRatio = 辺長平均の比
  • densityContrast = degreeExcess / edgeLenRatio² ← primary
  • densityContrast2 = 同じものをグラフ距離 2 以内の点集合について計算したもの
  • degreeCVRatio = 次数の変動係数の比（rev1 の primary。診断量として残す）

primary の形には理由がある。2次元では局所密度 ∝ 個数/長さ² なので、これは「粒子が自分の近傍越しに見る局所密度の、全体密度に対する過剰」の推定量になる。面積を固定する形（円・正方形・菱形・帯）では信号が個数の側に出て、個数を固定する形（k近傍）では長さの側に出るが、同じ一つの式が両方を拾う。形ごとに別の推定量を当てると「同じ観測器を当てた」と言えなくなるので、全形に同一の式を使った。

事前登録した判定（連言・K-14）:

clumped := (densityContrast >= 1.5) AND (densityContrast2 >= 1.5)
lambdaStar := 5シードの平均が clumped を最初に満たす λ

主張は観測量の字義まで狭める（K-14 の第三の対処・S-05 の道）。「相分離した」とは言わず、「その近傍定義から見た粒子重み局所密度が全体密度を 50% 以上超えた」としか言わない。

rev 1 の primary は本番の前に落ちた（K-15 の実例）

rev 1 は degreeCVRatio を primary にしていた。本番の掃引を一度も走らせる前に、正コントロール（Thomas 型クラスタ過程）に対して6形すべてで 1.02〜1.41 しか出ず、事前登録した閾値 1.5 を一度も越えないことが分かった。 K-15 が言う「事前登録した定義が正コントロールを1つも拾わない」状態そのものである。

原因は粒子重みの統計の性質にある。相分離した配置では粒子のほとんどが密相の内側にいて、粒子ごとの次数がそろって大きくなる。実際、本番の 5 シード平均で円近傍の平均次数は λ=0 の 5.99 から λ=0.75 で 41.0、λ=1 で 32.0 へ跳ね上がるのに、次数の変動係数のポアソン比は λ=1 で 1.000——つまりポアソン配置と区別がつかないままである。「不均一さ」を粒子ごとの分散で測ると、相分離はほとんど見えない。

秩序変数を取り替えた。閾値 1.5 は rev1 から一度も変えていない（対照に合わせて閾値を動かしてはいない）。差し替えの診断中に実系の λ = 0, 1, 2, 4 の値を見ているので、この4点については盲検ではない（K-11 に従い明記する）。

Gabriel グラフの検査が本番前に欠陥を1つ捕まえた。 最初の実装は候補の探索半径を局所の点間隔から決めていて、一様配置では総当たりと完全一致するのに、集積した配置では辺を 2 本落としていた。密相の内側では点間隔が小さいので探索半径も小さくなり、空隙をまたぐ長い辺を見落とす。Gabriel 辺の長さ d は「中点を中心とする半径 d/2 の空円」を要求するので d ≤ 2×(点集合の最大の空円の半径) が厳密に成り立つ——この上界を候補半径に据えて直した。一様配置しか検査していなければ、本番の集積した配置でだけ静かに間違っていた。

負コントロールは4種類用意した（K-14・K-17）。うち2つは「構造はあるが目当てのものではない系」である:

これが本スケッチの中心である。 「形を変えると答えが変わった」だけなら観測器が恣意的なだけかもしれない。ポアソン配置では変わらないのに実系では変わることを示して初めて、その形の違いが情報を運んでいると言える。

3. 分け方と数のどちらが効くか（Openshaw の比較）

形を disc に固定したまま、期待次数を 2 → 16 へ8倍振った:

λk̄=2k̄=3k̄=4k̄=6k̄=9k̄=12k̄=16

期待次数を 8 倍振っても転移点は動かない。期待次数を固定したまま形を変えると動く。 Openshaw の主張が、本系では結論の可否のレベルで成り立った。

なお、尺度の側が動かないのは偶然ではない。秩序変数を同じ尺度のポアソン参照集団で割っているからで、これは K-20 が挙げた scale problem の確立した対処（「半径を選ぶのをやめ、帰無と対比して報告する」）そのものである。確立した対処は scale problem を実際に飼い慣らした。しかし aggregation problem には効かなかった。

二つ書き添えることがある。

① 連言にした理由は、単独では負コントロールが通ったからである。 妥当性検査の段階で、densityContrast 単独（閾値 1.5）だと二量体過程が6形中4形で 1.50〜1.52 と閾値を越えた（k近傍 1.39、Gabriel 1.00 は越えない）。K-14 の手順どおり 2-hop の項を足すと二量体は6形すべてで落ち、正コントロールは6形すべてで通った。閾値は動かしていない。 ここで注意すべきなのは、同じ負コントロールが形によって「偽陽性」にも「正しく落ちる」にもなったことである。K-14 は「観測量によって特異性が変わる」と言うが、ここで変わったのは観測量ではなく近傍の形だった。

② Gabriel は正コントロールを 5 回中 3 回しか拾わない（平均 1.65、閾値 1.5 の直上）。パラメータを持たない形は較正の自由度が無いぶん恣意性が小さいが、感度（B2）も選べない。nc2_lattice でも Gabriel だけが 1.20 と、他5形（0.64〜0.72）と逆向きの読みを返す——Gabriel は規則的な配置を「ポアソンより密」と読む。同じ負コントロールに対する読みの向きが形で変わる。

事後解析（事前登録していない）

summary.json だけを読み直したもので、掃引は走らせ直していない（K-11）。

A. 「集積と判定される λ の区間」は形で大きく違う

lambdaStar は区間の下端しか見ない。上端まで見ると:

disc / square / diamond[0.5 .. 3]8/11 点
stripe[0.5 .. 4]9/11 点
knn[0.75 .. 4]8/11 点
gabriel[0.75 .. 2]5/11 点

Gabriel で読むと、集積が起きる λ の範囲は円で読んだときの半分強しかない。

B. 閾値を線形補間で横切る λ——散らばりの直接比較

ノブ横切る λ相対の散らばり
形（期待次数を 6.03 に固定）disc 0.351 / square 0.350 / diamond 0.351 / stripe 0.349 / knn 0.556 / gabriel 0.57652.8%
尺度（形を disc に固定）k̄=2: 0.347 … k̄=16: 0.3675.7%
帰無過程6形すべて横切らず—

9.3 倍。 これが本スケッチの最も端的な数である。

面白いのは形の内訳で、52.8% のほとんどは「面積を固定する形 vs 個数を固定する形」という一本の線から来ている。面積を固定する4形（円・正方形・菱形・帯）は互いに 0.349〜0.351 と 0.6% 以内で一致する——等方性を壊した帯ですらである。効いているのは形の幾何ではなく、「何を固定するか」だった。

**rev1 の観測量で読んでいたら、円・正方形・菱形・帯では「λ*=0.75 で現象が起きる」、k近傍と Gabriel では「どの λ でも起きない」という結論になった。 同じ配置、同じ力学、同じ閾値、同じ期待次数で、近傍の形が現象の存在そのものを決める**。

rev1 は正コントロールを拾えないので落として正解だが、落とす理由が「形で答えが変わるから」ではなかったことに注意がいる。正コントロールが無ければ、この観測量は生き残っていた。

本家サブプロジェクトへの含意（候補。要件化はしない）

  1. criteria.json の「スケール」欄は、値だけでは足りない。 K-9 は「秩序変数・スケール・閾値・参照点」の4つ組を要求するが、スケールには「大きさ」と「形」の2つの自由度がある。本系では形のほうが 9.3 倍効いた。登録欄に近傍の定義そのもの（何を固定するか——面積か個数か）を書く枠を足す候補。
  2. 「何を固定するか」を先に決める。 52.8% の散らばりのほとんどは、幾何の細部ではなく面積を固定するか個数を固定するかから来ていた。等方性を壊しても 0.6% しか動かない。観測器の設計でまず決めるべきなのはここという候補。
  3. K-19 は本番前の篩として使える。 ノブを1つ振るたびに帰無過程へ同じノブを振るのは、本スケッチでは追加費用が全体の 1 割以下だった（帰無側は力学を走らせないため）。掃引の設計に最初から組み込む候補。
  4. パラメータを持たない観測器は恣意性と感度を交換している。 Gabriel は較正の自由度がゼロだが、正コントロールを 5 回中 3 回しか拾えず、負コントロールの1つでは他5形と逆向きに読んだ。「パラメータが無いから客観的」とは言えないという候補。

限界（この実験が言えないこと）

  • 原典には到達していない。 Cates & Tailleur (2015) も Openshaw (1983) も本文を読んでおらず、MIPS の条件（d ln v/d ln ρ < −1）と MAUP の2成分という構造だけを既知の要約から採って、定義から自分で実装した。速度則の関数形（指数関数）・パラメータ（v0=0.35, 転回率 0.02, R=2.4, ρ=1/3）はすべて自分で決めたもので、原典の再現ではない。Openshaw が「分け方のほうが効く」と書いた根拠（彼は英国の国勢調査区の相関係数で示した）と本系の対応は確かめていない。
  • 2000 ステップで定常に達していない。 時系列（raw/trace.jsonl）を見ると λ=0.75 の円近傍は step 2000 でも 7.2 へ向かって上昇中である。粗大化は止まっていない。 ただし形の差は時間とともに開く（円/k近傍の比が step 200 の 1.25 から step 2000 の 2.77 へ）ので、短い走行が形の差を作っているのではない。走行長そのものは K-20 が挙げた未検査の次元②であり、本スケッチも振っていない。
  • 「形」を6通りしか試していない。 Openshaw の aggregation problem の核心は「分け方の総数が天文学的」ことにある（n 個の対象を m 区画に分ける仕方は Stirling 数で数える）。本スケッチが示したのは「6通り試したら 52.8% 散った」であって、最大どれだけ散るかの上界ではない。実際の散らばりはこれより大きいはずである。
  • 特異性は原理的に証明できない（K-20・Campbell & Fiske 1959）。4種類の負コントロールに対して連言が特異だと示しただけで、5種類目に対しては何も言えない。実際、二量体は連言を足す前には4形を通っていた。
  • 形の効果は1つの系でしか測っていない。 MIPS は密相と希薄相がはっきり分かれる系で、密相の内側は次数が一様になる。この性質が「面積を固定する形 vs 個数を固定する形」の差を作っている可能性が高く、別の種類の構造（繊維状・階層的）では順序が変わりうる。
  • lambdaStar の刻みは 0.25 で、形による差（0.5 対 0.75）は刻み1段ぶんしかない。 事前登録した結論としてはこれが上限であり、52.8% という数字は事後の線形補間から出ている。
  • 可視化は Claude が目視していない（本サブプロジェクトの既知の弱点）。viewer.html の API 整合は selftest が機械的に検査したが、配色・レイアウト・6色の辺が重なったときの見やすさは確かめられていない。
