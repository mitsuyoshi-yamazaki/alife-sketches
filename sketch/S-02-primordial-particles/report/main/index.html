一行で言うと

事前登録した測り方では「構造は現れなかった」。同じ生データを別の半径で測り直すと「ρ=0.04 で現れる」。 連結を判定する半径という、結論とは無関係に見える解析上の一数値を 2.0 から 2.5 へ動かすだけで、答えが「到達せず」から「ρ=0.04」へ跳ぶ。さらに第三の測り方（一様な場に対する近傍数の超過）では、密集は低密度ほど強いという逆向きの結論になる。

何をやったか

題材

粒子は位置と向きしか持たない。化学も結合も引力も無い。各ステップ、半径 r 内の近傍を数え、左右の偏りに応じて向きを変え、前へ進む:

Δφ = α + β · N · sign(R − L)

  N = 半径 r 内の近傍数
  L, R = そのうち進行方向の左側・右側にいる数
  <r=5, α=180°, β=17°, v=0.67>

これだけの規則から、境界を持つ塊が自発的に立ち上がる——というのが原典の主張である。S-01（静的な組合せ論）と対照的に、時間発展が目で見える系として選んだ。

核の側には「細胞」「膜」「生命」という語も概念も無い。あるのは粒子・向き・近傍・連結成分だけで、構造の呼び名は観測器の側にある（artificial-life の語彙分離と同じ切り分け）。

制御変数に密度を選んだ理由

原典の密度（DPE）を確認しようとしたが、Nature は認証の壁、PMC は CAPTCHA、研究室サイトは接続拒否、arXiv の PDF は本文を取り出せなかった。確認できなかったので、確認できない量をそのまま掃引の軸に据えた。

事前登録した閾値 0.5 には、ρ=0.2 まで一度も到達しなかった。

時系列（trace.jsonl）を見ると、これは発達の途中ではない。ρ≤0.15 では t=200 から t=2000 まで定常的にゼロである。一方 ρ=0.2 では t=200 で既に塊が17個あり、t=2000 で46個まで増え続けている。

世界を 300×300（7200 粒子）へ広げても ρ=0.08 では何も出なかったので、有限サイズ効果ではない。

そこで気付いたこと

ρ=0.08 における平均近傍数は 12.4 だった。一様にばら撒いた場合の予測は 0.08 × π × 5² = 6.3 である。約2倍。

平均近傍数が一様な場の予測を超えるのは、粒子が密集している証拠にほかならない。つまり構造は半径5のスケールでは確かに出来ていて、私が選んだ連結半径 1.5 では見えていなかった。

本家サブプロジェクトへの含意（候補。要件化はしていない）

artificial-life の A1（観測器の定義） への入力候補。採否はあちらで判断する:

  1. 秩序変数には「値」だけでなく「スケール」の自由度がある。spec-method §3.1 の事前登録は閾値を対象にしているが、閾値を固定してもスケールが自由なら結論は動く。S-01 で見つかった穴（どの秩序変数かを事前登録していない）と同じ穴の別の面にあたる。事前登録すべきは「秩序変数・そのスケール・閾値」の3つ組である
  2. スケールを恣意的に選ばずに済む測り方がある。「一様な場の予測に対する超過比」はスケールの選択を含まない（相互作用半径がそのまま使える）うえ、理論的な帰無値 1.0 を持つ。D1（帰無分布からの乖離）を実装する形として、連結成分より素性が良い
  3. 相互作用半径を連結判定に流用してはいけない。密度が上がると系全体が連結し、構造の有無と無関係に飽和する。観測のスケールは相互作用のスケールから独立に選ぶ必要がある

追記（2026-09-11・事前登録していない第二の事後解析）: 単位の誤りではないことの確認

S-10 のための文献調査が、本スケッチの結論に正面から反論した:

連続パーコレーション（Gilbert 円板模型）では浸透は λπr² のみに依存する。したがって半径 2.0→2.5 は 閾値を (2/2.5)² = 0.64 倍に予測どおり動かすだけで、半径に独立な情報は無い。 これは観測器依存の発見ではなく単位の誤りであり、無次元量 ρπr² で報告すべきである。

この批判は検証できる。 純粋なパーコレーションなら clusterFraction は無次元量 η = ρπr² だけの 関数になり、(ρ, r) の組が違っても η が同じなら同じ値を返すはずである。実測した（posthoc-percolation.js・生ログ）:

崩れない。 同じ無次元量で 0.08 から 0.93 まで散る。単位の誤りではない。

そして批判の論理が、より鋭い言い方を与える

λπr² の不変性はポアソン点過程に対して成り立つ定理である。本系の粒子はポアソンではない—— 構造化されていることこそが測定対象だった。だから対相関関数が固有の長さスケールを持ち、 連結半径はその異なる部分を探ることになる。

つまり:

半径が独立な情報を持つのは、配置がポアソンでないからである。ポアソンなら半径は冗長になる。 半径への感度は、恣意性の徴候であると同時に、構造の存在の証拠でもある。

当初の書き方（「解析上の一数値を動かすだけで結論が跳ぶ」）は、この二面性を落としていた。

限界（この実験が言えないこと）

  • 原典の密度を確認できていないため、「原典の設定で再現したか」は言えない。言えるのは、この実装で密度を掃引したときに何が見えたかだけである
  • 実装が原典に忠実である保証がない。運動則の式と定数は照合したが、初期配置・境界条件・更新順序・原典が使った世界の大きさは確認できていない。ρ=0.08 で構造が出ない結果は、原典との食い違いか、測り方の違いか、実装の違いかを切り分けられていない（事後解析は「測り方の違いで説明できる」ことを示すが、それが唯一の説明だとは示していない）
  • 「塊」が原典の言う細胞と同じものかを確認していない。連結成分の規模しか見ておらず、内部構造・寿命・分裂・複製は測っていない。原典の主張の核心（自己複製する構造）には触れていない
  • 事後解析はシード1本ずつ。事前登録した掃引は5シードだが、半径を振った表は各密度1本なので、揺らぎの幅が分からない
  • 観測は最終時刻の1点（時系列は1シードのみ）。構造が定常なのか揺らいでいるのかは分からない
