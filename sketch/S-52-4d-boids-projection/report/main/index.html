一行で言うと

4次元の群れを 256×256 の1枚のラスタへ落とす 16 通り（4→3 と 3→2 のそれぞれで 潰す／透視する／捨てる／移す）を、走行前に凍結した復号器で測ると、事前登録した主判定 Rb（近傍保存 J_6 ≥ 0.30）は16腕すべてで陰性、うち13腕は値がちょうど 0 だった——ただしこれは信号の不在ではなく、登録した二段中央値という集計が、12腕では全180フレームで例外なくフレーム内中央値を厳密な 0 へ落とすためである（個体あたりの J_6 は {0, 1/11, 1/5, 1/3, …} という離散値しか取らず、過半数の個体が未検出なら中央値は 0 になる）。床を受けない補助値（フレーム内平均）で同じデータを見ると 0.0000〜0.2080 の腕ごとの勾配が出て、その順位は 「画面に残った個体数」と Spearman 0.97 で一致する。すなわち主判定量をほぼ決めていたのは、載せた情報量ではなく 何個体を画面に残したか だった: 主効果は 正射影 +0.047 > チャネル +0.032 > 透視 −0.023 > 断面 −0.056 で、軸を丸ごと捨てる正射影が最良である（透視は箱の中心からの拡大で本番の 29〜57% を画布の外へ出し、断面は 85% を描かない）。加法モデルからの残差 RMS は 0.0506（登録閾値 0.06）で登録どおりに読めば「二段は独立に効く」だが、登録はこの場合を先に (iii)「表が床に張り付いたら観測器が弱すぎたという報告になる」と決めてあり、13/16 が 0 の表はまさにそれに当たる。中心的だった交絡の予測（A2×B2 透視×透視に最大の負の残差）は実測では残差 +0.0002 で、最大の残差は A1×B4 と A4×B1（片方が正射影・片方がチャネル）に正で出た。位置復元 O1 は逆に残存個体数とほぼ無相関（0.24）で、4軸すべてに情報を載せた A4×B4 が 0.2292 と最高である——「近傍は保たれるが位置は復元できない」腕と「位置は復元できるが近傍は壊れる」腕が別々に存在した。 そして分母を「描いた個体のみ」に替えると A3×B3（二段断面）の O1 は 0.0104 → 1.0000 へ跳ね、最下位級から最上位へ総入れ替わる（K-30 の実演）。

何をやったか

題材

一辺 L=1 の4次元トーラス T⁴ 上に N=96 個体を置き、分離（r=0.05、斥力 ∝ 1/r、重み 1.5）・整列（r=0.12、重み 1.0）・結合（r=0.12、重み 0.8）の3規則で走らせる。速さは [0.004, 0.012] にクリップ。burn-in 300 ステップののち、5 ステップおきに 60 フレーム × 3 シード（1,2,3）。主題は力学ではない——4次元の3規則は「近傍のベクトル平均へ寄せる」という形で次元に依らず一般化するので、登録は「この点で驚くことは何も無い」と先に書いている。問いは 2次元へ落とす段で2次元ぶん足りないときに何が起きるか にある。

16 腕（因子計画）

4→3（w の扱い）と 3→2（z の扱い）のそれぞれで4択:

  • ① 潰す（orth） 軸を捨てる。② 透視（persp） 視点距離 D=2.5L の中心投影で、捨てた軸が見かけの大きさに痕跡を残す。③ 捨てる（slice） 半厚 ε=0.05L のスラブ（中心は群れ重心の円周平均）の外を描かない。④ 移す（chan） 軸の値を明度（64 段、4–255）か大きさ（11 段、2–12 px）へ載せる（要求順に明度→大きさ）。

4×4=16 腕をすべて走らせた。u,v には常に x,y が載る。描画は画家のアルゴリズムで 256×256 の 8bit ラスタへ描き、復号器はそのラスタの画素だけから連結成分を取り、4次元状態 p̂ を推定する（復元できない軸には箱の中心 0.5L を入れる）。マークのリストではなくラスタを経由させるのは、重なり・量子化・クリップを損失として効かせるためである（登録事項）。

観測器（事前登録した6つ。分母は全 96 個体）

O1 位置復元率 R(τ=0.05L)（帰無値 0.00296、閾値 0.50）／O2 近傍保存 J_6（帰無値 0.0323、閾値 0.30、主判定）／O3 検出率（分母は「その腕が描いた個体」）／O4 幾何に載らなかった軸の Spearman ρ_z・ρ_w（閾値 min ≥ 0.50）／O5 速度方向の復元／O6 速度の参与次元 D_p（記述量。結論には使わない）。判定規則は Ra（O1）・Rb（O2）・Rc（O4 の min）の3つ。

⑥ 登録と実測が食い違った点（書き換えず、そのまま書く）

S2 が申告した3件を独立に検証し、うち2件は S2 の申告より広い範囲で起きていることが分かった。加えて S2 が申告していない食い違いが2件ある。

(a) NC2 の「重なり方は完全に同一」は、A4×B4 だけでなく 7 腕すべてのチャネル腕で成り立たない。 S2 は「大きさをチャネルに使う A4×B4 だけが O3 を動かす。明度のみの腕（A1×B4, A4×B1, A2×B4 等）では O3 は厳密に不変」と申告した。本レポートが seed 7 の20フレームで基準線を独立に作り直して照合すると、O3 が厳密に不変なのはチャネルを一つも使わない 9 腕（A1×B1, A1×B2, A1×B3, A2×B1, A2×B2, A2×B3, A3×B1, A3×B2, A3×B3）で、チャネルを使う 7 腕すべてで O3 が動く（フレームあたり最大差: A4×B3 0.3000、A4×B4 0.1250、A3×B4 0.0909、A4×B2 0.0667、A2×B4 0.0564、A1×B4 0.0417、A4×B1 0.0313）。機構は大きさではなく明度の側にある: 明度 64 段は 4–255 に割られるので下位3段の値は 5.96 / 9.88 / 13.8 であり、登録した二値化閾値 16 を下回って復号器から消える。軸の 4.7% がこの帯に入り、本番では1フレームあたり平均 4.8 個体（最大 10 個体）が「描かれているのに復号器には無い」状態になる。しかもこれらのマークは背景ではなく暗い値で塗られるので、見えないまま、下にあった明るいマークを消す。チャネル値を置換すればどの個体が暗くなるかが変わるので、重なり方は変わる。これは実装の誤りではなく、「大きさをチャネルに使う」および「明度の下端が二値化閾値を跨ぐ」という個別の定義と、NC2 の一般的な言い回しが両立しないことを意味する。登録の knobs 4 は「明度チャネルを使う腕では暗いマークが閾値未満に沈む。閾値はノブとして中立でない」と先に名指ししており、その現象が負コントロールの中で表に出たことになる。

(b) decisionRule の「A3/B3 を含む腕 6 つ」は 7 腕である。 独立に数え直して確認した: A1×B3, A2×B3, A3×B1, A3×B2, A3×B3, A3×B4, A4×B3 の 7 腕。実装は 7 腕で走っており（decision-rule.json の predictedGroupCountNote）、順位相関 0.2917 はこの 7 腕の版で計算されている。6 腕として計算した場合の値は生ログに無いが、順位予測の最下位群を1つ減らしても 0.70 を跨ぐ余地は無い（実測の最下位群には A2×B2 や A2×B4 のような非断面腕が混じっており、ずれの原因は群の大きさではない）。

(c) O2 の床は「検出率が 50% を割るフレーム」で起きるのではなく、12 腕では全 180 フレームで起きている。 S2 は「検出率が 50% を下回るフレームでフレーム内中央値が 0 になり、それが過半数のフレームで起きるとフレーム間中央値も 0 になる」と説明した。実測はそれより徹底している: 12 腕（A1×B2, A1×B3, A2×B1, A2×B2, A2×B3, A2×B4, A3×B1, A3×B2, A3×B3, A3×B4, A4×B3, A4×B4）ではフレーム内中央値が 180 フレーム中 180 フレームで厳密に 0、A4×B2 は 96.1% のフレームで 0 である（合計 13 腕が中央値 0）。検出率が 0.65 ある腕でも起きている（A1×B2 の O3 中央値は 0.6568）。より基本的な理由は統計量の離散性にある: k=6 の Jaccard は両側が 6 個なら {0, 1/11=0.0909, 2/10=0.2, 3/9=0.333, 4/8=0.5, 5/7=0.714, 1} しか取れず、96 個体の中央値もこの値しか取らない。登録した閾値 0.30 は 0.2 と 0.333 の間にあり、登録した雑音床 0.02 は隣接する到達可能値の間隔 0.0909 の 1/4.5 しかない。 登録が「際どい」と呼んだ 7 マスは、この量では原理的に閾値の近傍に落ちない。S2 が追加した補助値（O2_meanOfFrameMeans）はこの床を受けず、0.0000〜0.2079 の勾配を示す。

主判定量を決めていたもの

16 腕について、補助値と他の量の順位相関（本番のみ）:

近傍保存は「何個体を画面に残したか」でほぼ決まり、位置復元はそれと無関係である。 そして O3 検出率は、登録した情報量の順位のほぼ正反対に並ぶ——情報を多く載せた腕ほどマークが大きく重なり（A4×B4 の O3 は 0.4063 で16腕最下位）、情報を捨てた腕ほど検出しやすい（A3×B3 は 1.0000）。

画面外へ出た個体（登録されていない上限）

透視腕の「描いた個体数」が 96 を下回るのは、箱の中心からの拡大（S2 が README §実装上の決定 2 に挙げた、登録に無い決定）で画布の外へ出るためである。本レポートが core.js から状態を独立に再現して数えたところ、画面外へ出る個体はフレームあたり 28.2（透視が z 側）／35.4（w 側）／54.8（二段とも透視） で、生ログの nDrawn（68.63 / 62.73 / 42.35）を再現する。すなわち A2×B2 は本番で個体の 57% を画布の外に出している。断面（85% を描かない）に次ぐ脱落である。

登録は A1×B2 と A2×B1 の差を「段の順序そのものが効くか」の検査に指定し、差が出たら「描画順が w で決まっていることが第一容疑」と書いていた。実測の差は O2 平均系で 0.0155（床 0.02 未満）、O1 中央値で 0.0104（床 0.03 未満）で床を超えないが、描いた個体数では 68.63 対 62.73 と系統的に違う。機構は描画順ではない——描画順は画面外判定に一切関与しない。再現計算では、この期間の群れの重心が 平均 w = 0.571、平均 z = 0.487 と非対称に座っており、視点に近い w 側で拡大率が大きくなる（平均倍率 1.326 対 1.266）ためである。視点は箱に固定され、断面の中心は群れに追随する（どちらも登録事項）という非対称が、ここに出ている。

描いた後では次元が分からなくなる

PC1 の KS 統計量は、真の位置に対しては d=4 の式（0.0649）を採り d=3 の式（0.1688）を棄却するが、ラスタから検出したマークに対しては d=4 で 0.0589、d=3 で 0.1140 となり、登録した許容 0.15 の内側に両方が入る。すなわち 1枚の絵に描いて読み直した後では、動径分布はもはや元が4次元だったか3次元だったかを判別しない。 本スケッチの主題（2次元ぶん足りないと何が起きるか）に対する、副産物だが直接的な観測である。

NC2 の基準線の再計算

⑥(a) の照合のため、seed 7・burn-in 300・20 フレームの状態列を独立に再現し、凍結された observer.js で 16 腕を素の状態（チャネル置換なし）に対して走らせて基準線を作った。生ログには「seed 7 の素の状態を 16 腕で描いた条件」が無いため、NC2 の「O3 は全腕で不変」という登録の要求は、生ログだけでは検査できない。本レポートはこの再計算で検査した（結果は⑥(a)）。

本家サブプロジェクトへの含意（候補として挙げるだけ。要件化しない）

  1. 「見える」と「読み取れる」は逆向きに動きうる。 群れ規則を切ると検出率は 16 腕中 15 腕で上がり（NC1）、情報を多く載せた腕ほど検出率が下がる（O3 と情報量順位の相関 −0.93）。人工生命の観測で「よく群れている絵」を判断材料にするとき、絵の良さと状態の可読性が同じ向きだという暗黙の前提は、少なくともこの系では成り立たない
  2. 母集団の選択が写し方の順位を作る。 二段断面 A3×B3 は、全個体を分母にすれば復元率 0.0104（最下位級）、描いた個体だけを分母にすれば 1.0000（1位）である。同じ画像・同じ復号器で、分母を替えるだけで結論が反転する
  3. 次元を1つ落とすと、写し方の選択肢のいくつかは同一物に縮退する。 w が定数なら「捨てる／切る／チャネルへ移す」は数値まで同じ絵になった（NC4）。手筋の分類が意味を持つのは、その軸が情報を持つ場合だけである

S-51（3次元 boid の写し方）と並べて比べるための作法

S-51 の生ログはまだ出ていないので、ここでは比較の作法だけを書く。 登録（orderParameters の generalizationToDimension にあたる記述）は次を指定している:

  • O1 の生値を d=3 と d=4 で比べてはならない。 帰無値は R_chance = 1 − exp(−N·V_d(τ)/L^d) で、同じ τ=0.05L でも d=4 では 0.00296、d=3 では 0.0490 と 16.6 倍違う。比べるなら R / R_chance の比で比べること。本スケッチの実測をこの形に直すと、A4×B4 が 0.2292 / 0.00296 = 77 倍、A1×B1 が 0.0104 / 0.00296 = 3.5 倍、A3×B3 が 0.0104 / 0.00296 = 3.5 倍（描いた個体のみの分母なら 1.0000 / 0.00296 = 338 倍）である
  • O2（J_6）の帰無値 k/(2N−k) は d に依らない（k=6, N=96 で 0.0323）ので、直接比較してよい唯一の量である。ただし本スケッチの実測が示すとおり、登録した二段中央値では 13/16 腕が 0 に落ちるので、S-51 と並べるときは (i) 同じ集計（二段中央値）どうし (ii) 同じ補助値（フレーム内平均）どうし の2組を作り、どちらの組でも同じ結論が出るかを見ること。中央値の組だけで比べると、両者とも 0 の腕どうしを比べることになる
  • O3・nDrawn は d に強く依る（断面が残す割合は f₄=0.2106 対 f₃=0.1865、透視の拡大は二段とも透視なら d に依らず s² だが、画面外へ出る割合は群れの広がりに依る）。検出率を直接比べず、まず「描いた個体数」を揃えるか、それ自体を比較対象として明示すること
  • 腕の名前は共有できない。 S-51 は 3→2 の一段（4択）しか持たないので、S-52 の 16 腕のうち「A 段が恒等に相当する腕」は存在しない。比較可能なのは 手筋そのものの主効果（α と β） であり、本スケッチではそれが 潰す +0.047 / チャネル +0.032 / 透視 −0.023 / 断面 −0.056（4→3 段）と 潰す +0.041 / チャネル +0.029 / 透視 −0.012 / 断面 −0.058（3→2 段）である。S-51 の一段の効果と並べるべきはこの β のほうである

限界（この実験が言えないこと）

  1. 出典の到達度。S1 は「全文に到達した原典は1つも無い」として登録した（sourceFidelity）。その登録は S1 の時点では正しいが、同日の別経路の調査（work/2026-09-17-4d-visualization-sources.md）はいくつかの原典に到達している。 criteria.json は凍結してあるので書き換えず、差をここに書く:
  • Noll 1967 は本文に到達できる（HTML 再録 content-animation.org.uk/htmls/noll67.htm）。登録は「抄録のみ到達」と書いた。本文は平行投影を透視投影の視点無限遠の極限として同じ構成の中に置いており、本スケッチが①と②を別の手筋として並べた扱いは、原典の扱いと同じではない。視点距離 D=2.5L が Noll の値ではないという登録の但し書きはそのまま有効である。またNoll は結論で「4次元への深い感覚や洞察が実際に得られたわけではない」と書いている
  • Schlegel の年について、S1 の「訂正」（1883 → 1886）が訂正になっていない可能性がある。 Coxeter 自身の文献表では Schlegel 1883（Nova Acta 44, pp. 343–459）と Schlegel 1886（Waren）は別の文献で、図の初出は 1883 側（pp. 353–358 + Taf. 1）とされる。本スケッチの結論はこの年号に依存しないが、登録に書いた「訂正」は確定していない
  • Cleveland & McGill の順位（面積 > 濃淡）は原典未照合である。 登録はこれを borrowedConstants に置き、「本スケッチは明度 64 段・大きさ 11 段としたので機械では順序が逆転する」と書いた。実測でも逆転している（NC4 で同じ情報量の軸が、明度に載れば 0.6250、大きさに載れば 0.2917）。ただし借りた定数の出所が原典で確認されていないので、「人間の順位と逆である」という対比そのものが二次資料に依っている
  • 「描いた画像から元の状態を復号する」という評価法に、確立した先行が見つかっていない。 最も近いのは inverse projection / unprojection（arXiv:2111.01744）だが、技法であって評価手順ではない。既存の投影品質指標（trustworthiness / continuity / co-ranking / stress）は埋め込み座標から測るもので、画素を経由しない。したがって本スケッチの観測器は引用のある既存物ではなく、こちらが作り込んでいる空白であり、既存指標との比較可能性を持たない
  • Coxeter は等傾斜回転を "Clifford displacement" と呼び、"isoclinic" の語は『Regular Polytopes』に一度も現れない。 登録は「等傾斜（isoclinic・Clifford 変位）」と書いている。RP3 を非等傾斜（角速度比 1 : 1.618）に取った判断そのものは Coxeter の本文（「2枚の完全直交平面は ξ₁ = ±ξ₂ の場合を除いて一意に定まる」）と整合する
  • 4次元以上の boid の先行例は見つかっていない。ただし「先行例が無い」とは書かない。 Cucker–Smale (2007) は ℝᵈ の任意 d で定義されており、連続体・統計物理側の flocking 文献は日常的に任意次元で書かれている。正確な言い方は「力学は一般化する。未解決なのは表示だけ」である
  1. Banchoff 1990 の警告と正面から衝突する設計である。 Banchoff は「Schlegel 多面体の1枚の写真はかなり紛らわしくなりうる」として動画や立体視対を勧めている。本スケッチは静止画1枚から復元を測る。したがって本レポートの低い復元率は、1990 年に既に言われていたことの再確認にすぎない可能性がある。 本スケッチが足しているのは「どれだけ紛らわしいか」を機械可読な量にしたことと、16 通りを同じ物差しで並べたことだけである。なお viewer.html は実時間で動かせるので動画としての観察は可能だが、判定はすべて静止画1枚に対して行われている
  2. 測ったのは機械可読性であって人間可読性ではない。 復号器は人間の明度弁別限界（Bertin / Cleveland & McGill の言う数段）を持たない。明度 64 段・大きさ 11 段という選択は機械の復号器に対する上限であり、本スケッチの順位を人間の見やすさの順位として読んではならない
  3. 登録が指定していなかった実装上の決定5件のうち、少なくとも1件は結論を大きく動かしている。 (i) 積分ゲイン 0.1 ——群れの密度と φ ≈ 0.02〜0.15 という疎らな定常状態を決めており、近傍密度が変われば O2 の水準は変わる。(ii) 拡大の中心（箱の中心からの拡大）と、画布外のマークを描かないこと ——これが透視腕の 29〜57% の脱落を作り、O2 平均系の順位と描いた個体数の相関 0.97 の相当部分を作っている。5件のうち結論への影響が最も大きい。 視点を群れの重心に置くか、拡大後に画布へ収める正規化を入れれば、透視腕の主効果 −0.023 は変わりうる。(iii) 描画順を w+z の和で決めたこと ——画面外判定にも検出にも直接は効かず、影響は重なりの上下関係に限られる。(iv) 捕捉半径 12 px ——O1・O2 の対応付けを支配するが、掃引が無いので効きの大きさは不明である。(v) 融合の基準面積を腕ごとの最大半径で取ったこと ——O3 の「融合」旗の数に効く（本番で A1×B1 は 15.5 個体/フレーム、A2×B3 は 0）が、判定に融合数は使われていない
  4. 判定の表が床に張り付いている。 登録した主判定量は 16 マス中 13 マスで 0 であり、登録自身が先に「そうなったら観測器が弱すぎたという報告になる」と書いた場合に当たる。したがって「二段は独立に効く」という一次判定は、ほぼ零の表に加法モデルを当てた出力であると理解しなければならない。登録の申し送りに従えば、疑うべきは τ や k ではなく 画布の解像度（256 px）と個体数（96） であり、マーク半径 4 px の円 96 個は 256×256 の 4.7% を覆うので、重なりは設計から避けられない
  5. 雑音床は実測より小さく見積もられている。 登録の床は O1 で 0.03、O2 で 0.02 だが、実測のシード間差は O1 中央値で最大 0.1146（A4×B4）、O2 平均系で最大 0.0576（A4×B1） と、上位の腕ほど床を超える。上位 4 腕どうしの差は、登録した床では判定できない
  6. 一点のパラメータでしか測っていない。 N=96、r_ali=r_coh=0.12、4次元という組み合わせは近傍密度が非常に低く（期待近傍数 ≈ 0.1 個）、群れは単一の塊にならず疎らな複数クラスタで定常になる。密な群れでの写し方の順位は、この走行からは言えない。
  7. 対照の一部が生ログの中で完結していない。 NC1 の「検出率が本番より高い」は controls.json では null のまま（本レポートが数え直した）、NC2 の O1 は記録されず、NC2 の不変性を照合するための「seed 7 の素の状態」条件が無く（本レポートが再計算した）、NC4 の PC1 再検定は行われていない。登録した対照の主張のうち4件は、生ログだけでは検証できない。
  8. RP3（二重回転）が4次元固有の状態として成立していたかを、生ログは示していない。 妥当性検査に使われた基準（D_p > 2.2）は、二重回転を課していない本番も通る（本番 3.73、RP3 3.78）。「4次元にあって3次元に無い構造を足した」という参照点の前提は、確かめられていない。
  9. 順位の一部は定義上ほぼ決まっている。 登録が 48 マスを1マスずつ点検して [定義上自明] [ほぼ定義上決まる] と旗を立てたマス（正射影で潰した軸の ρ、断面腕の ρ、チャネル腕の Rc など）は、本レポートでも証拠として使っていない。とくに「チャネルは正射影より良い」という向きの結論は構成上ほぼ決まっており、本スケッチの発見ではない（登録の _comment に明記）。本レポートが発見として扱ったのは、その構成上の期待に反して 潰す がチャネルを上回ったことと、その理由が情報量ではなく残存個体数だったことである。
