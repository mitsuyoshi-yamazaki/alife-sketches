1. 問いへの答え

1.1 重力だけから何段が出たか

!図1

この走行からは答えられない。 登録の観測器で数えた段は、S・L・R の 13 本と NC-G0・E-geo・dt-check の全 16 本で D=0・D_noWeb=0 だった（runs.jsonl）。L1（ハロー）は f_halo=0 で、20 粒子以上の FOF 群は全出力で 0 個。L3（網）は D_T=0.004〜0.011（S-cut だけ 0.093・0.104）、MV_fil=1.000〜1.003 で、網に質量が集まった形跡が無い。L2 は親（1000 粒子以上のハロー）が無いので数える対象が無い。

S4 は実装と独立に書いた FOF（fof_indep.js）で、途中保存の粒子の位置（S-n0・S-n1・S-cdm、a=0.90〜0.94）を数え直した。連結長 0.2 Δ₀ の内側に入る粒子の対は 1 つも無かった（3 本とも連結 0 本・最大の群 1 粒子）。観測器は目の前の状態を正しく 0 と数えていた——構造が無かったのは観測器のせいではなく、箱の状態のせいである。

図1の左は本番の S-cdm seed 6101 の a=0.90 の断面で、4096 ビンのすべてがちょうど 8 粒子——初期の格子のままだった。格子点からの rms の変位は S-cdm で 0.005 Δ₀、S-n1 で 0.019 Δ₀、最大の S-n0 でも 0.094 Δ₀（最大 0.40 Δ₀）で、登録が見込んだ a_f の変位（数 Δ₀ の非線形）に遠く届いていない。

1.4 初期の揺らぎのスペクトルと分解能で何が変わったか

!図2

登録の観測量では、どの軸でも何も変わらなかった（すべて 0）。そのうえで二つのことが言える。

(1) 走ったスペクトルは登録のスペクトルではなかった。 実現した Δ²(k) は登録の形に k³ を掛けた形になる（図2の橙の点の傾き）。n=−1 の腕は実際には Δ² ∝ k⁵（n=+2 相当）、n=0 の腕は n=+3 相当、CDM 型も小スケールで持ち上がった青い形、切ったスペクトルも n=+2 に切りを掛けた形だった。「冪・CDM・小スケールを切ったもの」の比較は、登録した 4 通りの比較としては行われていない。

(2) 分解能の格子は、同じ実現の比較になっていない。 128³ の腕は n が 8 倍なので Δ² の係数 1/n² が 64 分の 1 になり、実現値で S-cdm の約 80 分の 1 だった（L-cdm の Δ²(3k_f)=8×10⁻¹¹）。登録が C2 の「質量の軸」に使う S-cdm → L-cdm の比較は、振幅の違う 2 つの線形の箱の比較になっていた（S2 の申し送り §2 の「大スケールのモードを共有しない」に加えて）。

線形のままの箱で測れた違いは変位の大きさだけで、S4 の回帰（途中保存の変位を初期の変位場へ回帰。growth.out.jsonl）では次のとおりだった。大スケールのモードだけを持つ S-cut では傾き 0.819 対 線形理論の a=0.823で、PM の力学が線形成長を 0.5% で再現していることの直接の証拠になる。小スケールの力を持つ腕では、初期の変位場に沿った成分が線形より速く（S-n1 4.6 倍、S-n0 6.9 倍、S-cdm 2.9 倍）あるいは遅く（R1 0.45 倍、R3 0.79 倍）育っており、メッシュの細かさに対して単調でない。振幅が格子間隔の 10⁻³ 程度しかない状態で、格子の離散性のモードが成長率を決めていると読める（事前登録していない解釈。§5）。

2. 何をやったか

2.1 題材

膨張する Einstein–de Sitter 宇宙の共動座標（周期箱 L=64Δ₀、ρ̄=1、G=3/(8π)）で、等質量の粒子を粒子メッシュ法（CIC・7 点差分のグリーン関数・4 点差分の勾配）と ln a で等間隔の KDK leapfrog（Δln a=0.015）で発展させる。初期条件は格子に Zel'dovich 近似で揺らぎを与える。上位の単位は核に一切書かない。腕は、S（64³ 粒子・メッシュ 128³）の 4 スペクトル × 2 seed、L（128³/256³）の cdm と n=−1、分解能の格子 R1（64³/64³）・R3（64³/256³）・R4（128³/128³）、負コントロール NC-G0（重力なし）・NC-1mode（平面波 1 つの崩壊）・NC-eq（静止した箱の Plummer 球）、較正の E-geo（力だけ 1.1 倍）と dt-check（刻み半分）。

2.2 観測器

L1 = FOF（b=0.2・20 粒子以上）のハロー、L2 = SUBFIND の簡略版で見つけた部分ハローのうち以前は独立のハローだったもの（H-strict）を 1000 粒子以上の親が抱くこと、L3 = T-web（64³ 格子・R_s=2Δ₀・λ_th=0）の糸のセルの連結成分でハローを 2 個以上含むもの。段の数 D=[L1]+[L1∧L2]+[L1∧L3]。各段に A4 の署名（束縛・ビリアル比・次元）を付け、落ち込みの事象を芯の ID で追跡する。台帳は Winther の Layzer–Irvine の比 ε=σ/Σ。

2.3 妥当性検査

selftest は 25 項目で、gate.js state S-61 の s2 は ✅（S4 の時点で再実行された）。ただし §4.1 のとおり、初期条件の振幅の実現値を登録値と突き合わせる項が 1 つも無く、振幅が 1 万倍違っても通る構成だった:

  • positiveControls[3]（線形成長）の selftest は力学を 1 刻みも進めていない。a_i の粒子配置の CIC 密度と、入力した δ_k の a_i 倍を比べる整合の検査で、比を取るので振幅に無感（登録の文言は「最初の出力群で δ_k(a)/δ_k(a_i) が a/a_i と 3% 以内」で、時間発展の検査である）
  • positiveControls[7]（Doroshkevich）は固有値の符号だけを見るので振幅に無感
  • positiveControls[11]（a_i・刻み数の再計算）は computeStartA の連続極限の解析値どうしの比較で、生成した場を見ない
  • negativeControls の NC-G0 の項目は steppedWithForceScale(…, 0) を直接呼んでおり、本番の spec の経路（|| 1 で 0 が 1 に化ける）を通らない。しかも振幅の誤りのもとでは重力があっても 10 刻みでハローは出ないので、処置の腕でも同じく通る

6. 本家サブプロジェクトへの含意（候補）

候補として挙げるだけで、要件化しない。採否はユーザが個別に判断する。

2. 何をやったか

2.1 題材と観測器

1回目と同じ（main.md §2.1・§2.2）。膨張する Einstein–de Sitter 宇宙の共動座標で等質量の粒子を粒子メッシュ法で発展させ、上位の単位は核に書かない。観測器は L1 = FOF（b=0.2・20 粒子以上）、L2 = SUBFIND の簡略版の持続する部分ハローを抱く 1000 粒子以上の親、L3 = T-web の糸のセルの連結成分、段の数 D=[L1]+[L1∧L2]+[L1∧L3]。

2.2 2回目で直したもの

raw/notes.md §21 のとおり: 初期条件の振幅の規格化（と |k|≤k_Ny,p の球での切り）、NC-G0 の重力の配線（protocol.js と run.js の二重の || 1）、束縛の判定の球対称近似の外殻の寄与と A4 の W *= 0.5、出力の頻度（FOF 出力 Δln a≈0.1・完全出力 Δln a=0.25）、欠けていた生ログの欄（timeseries の Δ²(k)・質量関数・網の指標、ledger の刻みごと全件、halos・events・snapshots）、controls.json の seed の比較、縮退段の決定の永続化。登録（criteria.json）は変えていない。

2.3 妥当性検査

selftest は 31 項目（raw/notes.md §21）。S4 は selftest を走らせていない——走らせると1回目の raw/threshold-report.json を上書きするためで、2回目の値は親が写した raw/run2/threshold-report.json を読んだ。緩めた正コントロールの線は1回目と同じ4つで、[3] 線形成長の振幅 0.0399（登録 0.03・緩めた線 0.05）・位相 0.0367 rad（0.03・0.05）、[4] 殻の交差 σ_x 0.207（0.10・0.25）・σ_v 0.168（0.15・0.30）。どれも決定規則の条件には入っていない（1回目 §3.5 と同じ）。

selftest の範囲について S4 が読んだこと:

  • 再開の決定性（K-140）: selftest の「本物の Worker 経由で中断→再開しても、中断しなかった走行と最終状態のハッシュが一致する」は 8³ 粒子・メッシュ 16³・8 刻みで、締切による中断（保存してから止まる）だけを検査する。外から止められて最後の周期保存から再開する経路と、ハローや未決の事象を抱えた出力をまたぐ再開は検査されていない。本番の生ログでは、再開をまたいだ走行の台帳に飛びが無く（§1.6）、周期保存から S4 が再現した最終状態のハッシュが S-cdm・L-cdm・NC-G0 で記録と一致し、L-n1 では別の起動が重ねて走らせた 251 刻みが記録とビット一致した（§2.4・§4.1）。これで本番の範囲の再開は決定的だったと言える
  • [9] ④の較正: selftest の名前は「AR(1) 合成系列と NC-eq」だが、中身は AR(1) だけで、NC-eq の④は selftest でも本番でも計算されていない。しかも AR(1) の傾きを ln a ではなく出力の番号（1 出力 = Δln a 0.1）に対して取っており、登録の線 γ_M≥1 の 10 倍厳しい線で数えている（§3.2 の C5）
  • NC-G0: 本番と同じ経路（protocol.js→run.js）で重力が切れることを短縮規模で検査する項目が足された。本番でも切れていた（§4.1）

L の腕（128³）の T-web の平滑化が登録の半分だった。 実装は R_s=2×（粒子の平均間隔）で、128³ の腕では 1Δ₀ になる（登録は Δ₀=64³ の平均間隔を単位に R_s=2Δ₀）。S4 の T-web で L-cdm の最終状態を数えると R_s=1Δ₀ で MV_fil 1.4851（記録と一致）、登録の R_s=2Δ₀ で 1.3746。knob の格子も L の腕では {0.5, 1, 2}Δ₀ にずれている。③の合否は動かない（どちらも 1.5 未満）が、L-cdm の⑦の陽性（唯一の⑦陽性）はこの平滑化で MV_fil がちょうど 1.500 に届いた1点に依っており、登録の平滑化の完全出力では 1.30（a=0.37）・1.38（a_f）なので陰性だった見込みが高い（FOF 出力ごとの値は途中の状態が無く確かめられない）
  3. s_surv は存在しない欄を読み、構造上 0 だった。 computeRules は事象の nAtInfall と becamePersistentSubhalo を読むが、事象に書かれる欄は n_at_infall と fate である。分母が常に空になり s_surv=0（「0 件中 0」）。aggregate.js の上限の記録も同じ欄を読み、溶けた割合が構造上 1 になる。S4 の数え直しは §1.3（S-n0 6101 の 0.03 のほかは 0）。値はほぼ動かないが、記録の 0 は測定ではない
  4. ②の観測器は登録より狭い。 SUBFIND を掛けるのは各完全出力で 100 粒子以上の大きい方から 3 つだけ（登録は 100 粒子以上の全て）、持続の判定は直前の FOF 出力だけと比べ、重なりの分母は前のハローの粒子数（登録は部分ハローの粒子で「以前のある出力」）、角度を混ぜた参照 N_ps,shuf は規則の中で 0 に固定。L の腕で親が 174・214 個あっても N_host,ps≥3 には見た 3 つ全てが要る。②の陰性と C2 は、この制約の下の値である
  5. C5 の機械判定は、記録の無い NC-eq の④を陰性と数えていた（aggregate.js の !(ncEq.rule4 && ncEq.rule4.pass)）。S-65 の1回目と同じ「定義されているか」で判定を出す型。C1 も NC-1mode の D が無い（undefined <= 1 が偽）ので evidence から欄が落ちている（判定は他の条件で不成立なので動かない）
  6. NC-G0 の台帳の W は重力ありのポテンシャルで数えられていた。 力を 0 倍にしても run.js は W を元の G の pmForce から数える（E-geo の「W は元の G で数える」と同じ扱い）。登録の NC-G0 は φ=0 なので W=0 で、そのとき Winther の Σ は解析的に 0（K∝a⁻² で ΔK と ∫2K dln a が打ち消す）になり ε は 0/0。S4 が W=0 で計算すると σ は K の初期値の 10⁻⁴ 程度で閉じる。予測「⑤ 1 中 1（構成上ほぼ厳密）」の外れは、この定義の食い違いから来ている
  7. ⑤の評価区間が登録と違う（実装は後半の刻み、登録は [a_i e^{0.5}, a_f]）。どちらでも全走行で不合格なので合否は動かない。値は登録の区間のほうが大きい（S-cdm 0.075→0.57）

4.3 判定は動かさないが、記録が誤る・薄いもの

  1. 完全出力が FOF 出力の中に入れ子になっていて、各走行 3 回しか起きない。 run.js は if (isFOF) { … if (isFull) … } の形で、完全出力の刻み（Δln a=0.25 ごと）が FOF 出力の刻み（7 刻みごと）と重なったときしか処理しない。S-cdm の完全出力は a=0.105・0.774・0.999 の 3 回、dt-check は a_f の 1 回。knob の全振り（登録 3 時点）と snapshot（登録 4 時点）も重なった時点だけで、S-cdm の snapshot は a_i と a_f の 2 枚。1回目の S4 が指摘した出力の間隔の直しで入った新しい欠陥である
  2. 事象の記録: infall の成り行きのうち「通り抜け」が無く、次の完全出力まで決まらなかった事象が pending のまま 26〜462 件残る。明滅（remerged）は infall 型の別の行として足され、④の事象の枝の r_inf は明滅を除かず（flicker の欄が無い）、しかも1ハローあたりに割っていない（件/出力/0.5）。④は成長の枝で立っているので合否は動かない
  3. f_asm は登録の粒子の追跡ではなく、全体の f_halo の比（5 出力前の f_halo ÷ いまの f_halo）で近似されている。⑦の合否は t_emerge(L3) で決まっているので動かない
  4. knob の段の判定は L3 を D_T と MV_fil だけで数え、λ_th>0 では D_T の参照（λ_th=0 の Doroshkevich の体積比）が合わない（§3.4）
  5. 糸の単位は周期をまたぐ成分を登録どおり 8 つに切っていない（箱を貫く網が1単位。ハローを2個以上含む糸の単位は S の腕で 1〜2、L の腕で 8・11——箱を貫く1つの成分と、平滑化が細かいため割れた小さな成分）
  6. snapshot のハローの見かけの半径は、周期境界をまたぐ群で箱の大きさ（64.7Δ₀）になる（S-cdm の a_f で 195 個中 2 個）
  7. ceilings/ の記録が1回目の起動のまま（§3.5）
  8. run.log は6回目の起動が開き直したので、1〜5 回目の記録は5回目の末尾の数行を除いて残っていない

5. 事後解析（事前登録していない）

この節は結果を見た後に S4 が足した解析で、§3 の判定には一切使わない。

台帳が開いた中身は、走り始めの格子の自己エネルギーの過渡だった。 刻みごとの σ/|W|（li_r2.js と同じ台帳から）は、S-cdm で a=0.10 の 0.15 → 0.21 の 0.085 → 0.47 の 0.019 → a_f の −0.004 と縮み、a_f では |W| の 0.4% しか開いていない。S-n0 は a=0.021 で 1.76 まで開いてから a_f の 0.28 へ、S-n1 は 0.82 から 0.048 へ縮む。開き方は a_i が早い腕ほど大きく（S-n0 0.0057、S-n1 0.019、S-cdm 0.045）、a_i の W は自己エネルギー（shotEnergyRef −5.0×10⁴ を a で割った値。S-n0 の a_i で −8.8×10⁶）に支配されていた（S-n0 の最初の W は −7.4×10⁶）。自己エネルギーが 1/a に比例するだけなら Layzer–Irvine の式を自分で満たすが、粒子が格子の中で動くと位置に依存する分が力と整合しないまま変わる（raw/notes.md §1）。メッシュ＝粒子格子の R1 は初めから小さく（a_f で −0.043）、1回目の S4 の読み（自己エネルギーの優勢は 10⁶ 倍小さい K で水増しされていた）のとおり、振幅を直すと中盤以降は閉じる方向に向かう。登録の線 0.02 と区間の定義のもとでは、この過渡だけで⑤は外れる。

「小さいものが先」の時系列。 20 粒子以上の群が最初に現れる a と 1000 粒子以上の群が最初に現れる a は、S-n1 0.155→0.751、S-n0 0.065→0.730、S-cdm 0.198→0.774、R1 0.220→0.774、S-cut 0.170→0.259。冪乗則と CDM 型では大きな群が小さな群の 4〜11 倍遅い a に現れ（下から上）、切ったスペクトルでは 1.5 倍（ほぼ同時）。M_c は S-cdm で a=0.3 の 38 から a_f の 465 へ、S-cut では 628 から 12,211 へ育った。

網の質量の集まりの上限。 MV_fil の最大は、64³ の冪乗則と CDM 型で 1.23〜1.39（a=0.3〜0.75）、L の腕（実装の平滑化）で 1.44・1.50、S-cut で 1.53・1.55 で、どれも途中で頭打ちになる（図2(c)）。糸のセルの体積は 0.31〜0.37 と大きく、その多くを質量の薄いセルが占める。質量はハローに集まるにつれて節（MV 9〜20）へ移り、糸のセルの平均の密度は 1.4 倍前後から上がらない。λ_th=0 の T-web で「糸に質量が 1.5 倍集まる」という登録の線は、この分解能と箱では届かない位置にあった可能性がある（検証していない）。

6. 本家サブプロジェクトへの含意（候補）

候補として挙げるだけで、要件化しない。採否はユーザが個別に判断する。

  • 重力だけの N 体で、粒子→ハローの段は初期の揺らぎのスペクトルの形に依らず立ち、ハローの中は質量だけが違う相似な繰り返しだった（100 粒子のハローも 3000 粒子の親も束縛・ビリアル化・3 次元）。「新しい性質の出る段」は粒子→ハローの1回で、ハロー→大きいハローは同じ性質の繰り返しである。S-64（DLCA、形の繰り返しの基準線）と並べる材料になる
  • 網は「境界のある単位」としては弱い。 位相（糸のセルの連結）では箱を貫く1つの網がはっきり出る一方、質量の集まりで線を引くと閾値しだいで出たり消えたりする。S-60 が網を段に数えなかった判断と、本件の「閾値しだい」は同じ事実の両面と読める
  • 下の段が上の段に部品として残るか（H-strict）は、観測器が見る親の数と追跡の窓に強く縛られる。 部分ハローを「以前は独立だった」と判定する窓が直前の出力だけだと、生き残った部分ハローほど数えられない。階層の保持を問う実験では、追跡の窓の長さが結論を決める

7. 限界

  • 網の段（L3）と入れ子の段（L2）について、登録の問いに答えきっていない。 L3 は MV_fil の線 1.5 で外れ、knob で覆るので「閾値しだい」までしか言えない。L3 の単位の署名は計算されていない（§4.2-1）。L2 は観測器が上位 3 つの親と直前の出力しか見ず、s_surv は構造上 0 なので、過剰合体か保持かを判定できない（§4.2-3・4）
  • R3・R4 が走っていない（縮退段 2）。分解能の格子は R1・S-cdm・L-cdm の 3 点で、C2 の代わりの読みの力の軸は組めない
  • NC-1mode の規則が記録されていないので、C1 の NC-1mode の条件と罠のマス 7 つは読めない。NC-eq の①〜④⑥⑦も記録されておらず、C5 の較正の半分が欠ける
  • 台帳は閉じず、較正の腕も区別できないので、「タダのエネルギーが無い」は言えない。事後の読み（過渡の自己エネルギー）は検証していない
  • 各腕の多くは 1 標本（L・R・NC）、S の腕は 2 seed。単一の実現の揺らぎ（3k_f の殻で ±14%）は腕どうしの比較に効く
  • 完全出力が各走行 3 回だけなので、部分ハローの持続・事象の成り行き・knob の全振りは粗い時点でしか測られていない
  • 再実装の忠実性: 原典の再現ではない（sourceFidelity）。Millennium と分解能が 3〜4 桁違い、背景は EdS、力は PM だけ、初期配置は格子、銀河の段は実装しない。BBKS・Davis ら・Doroshkevich・Zel'dovich・Layzer／Irvine・Press–Schechter は登録時に本文に到達しておらず、本 S4 も原典を読み直していない。S4 の BBKS の式も記憶から書いたもので、CDM 型の腕の殻の比（1.05・1.04・1.17）が n=−1 の腕と揃うので実装の式と同じ形だと読めるが、原典とは照合していない
  • リポジトリに入っていない生ログ（1MB 以上。ローカルにだけある）: raw/run2/events.jsonl（14.3MB）・halos.jsonl（4.0MB）・timeseries.jsonl（3.5MB）・ledger.jsonl（1.0MB）・checkpoints/（42 ファイル・381MB）。§1.3 の s_surv の数え直し・§1.5 の④・§1.6 と §2.4 の台帳・§4.1 のハッシュと T-web はこれらに頼っており、消えると再現できない（初期の振幅の再計算は実装のコードだけから再現できる）。なお途中保存は最後の周期保存（20 刻みごと）で最終状態そのものではなく、L-n1 のものは6回目が中断時に書いた 251 刻み目の状態である
  • 1〜5 回目の run.log と ceilings/ の更新は残っていない。どの回にどの腕が走ったかは途中保存・snapshot の更新時刻とコミットからの推定である
  • S4 は selftest を走らせていない（§2.3）。機械は他の本の本番と CPU とメモリを分け合っていた（load average 約 6.5）
